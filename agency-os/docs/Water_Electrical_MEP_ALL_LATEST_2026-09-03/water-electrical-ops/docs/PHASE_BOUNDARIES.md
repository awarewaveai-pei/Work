# Phase Boundaries

P1: identity/workforce/project/dispatch/calendar/LINE/Google/RWD + bounded offline sync.
P2: field execution/documents/photos/quality; offline write scope may expand only through explicit contract.
P3: procurement/material.
P4: commercial/subcontract/labor_time/cost/accounting_integration. Approved labor time drives labor cost. No online payment gateway.
P5: AI read/query/summary/analysis behind existing authorization.

No multi-tenant SaaS productization is planned. Deferred modules are deliberately absent from Phase 1 implementation paths.
