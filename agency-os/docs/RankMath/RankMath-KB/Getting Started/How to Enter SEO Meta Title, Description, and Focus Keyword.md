# How to Enter SEO Meta Title, Description, and Focus Keyword

			
			

	

In this knowledgebase article, we’re going to walk you through how to enter the SEO Meta Title, Description, and Focus Keywords in the Classic Editor, Gutenberg, [Elementor](https://rankmath.com/blog/elementor-seo/) & [Divi](https://rankmath.com/blog/divi-seo/).

## 1  Using the Gutenberg Block Editor

To add SEO meta tags with Gutenberg Block editor, at first, open the post/page where you want to add the SEO metadata and click on the Rank Math icon at the top right corner in the WordPress menu.

![Rank Math icon in Gutenberg Block editor](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20877%20202'%3E%3C/svg%3E)

Alternatively, you can also click on the three vertical dots and choose Rank Math from the list of options.

![Rank Math option in Gutenberg Block editor](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20538%20965'%3E%3C/svg%3E)

### 1.1  Add SEO Meta Title in Gutenberg

To add SEO title in the Gutenberg Editor click on **Edit Snippet** in the Rank Math General tab as shown below:

![General Tab of Gutenberg](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20594%20976'%3E%3C/svg%3E)

Once you click on Edit Snippet you will get a new window where you can set the title in the **Title**section.

![Add Title- Gutenberg](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201270%20794'%3E%3C/svg%3E)

### 1.2  Add Description in Gutenberg

You can add the description in Gutenberg in the**General tab** of Rank Math. Click on **Edit Snippet** and enter your description in the **Description**box.

![Description in Gutenberg](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201266%201350'%3E%3C/svg%3E)

### 1.3  Add Focus Keyword in Gutenberg

You can set the Focus Keyword in Gutenberg in **Rank Math Metabox → General tab →** **Focus Keyword.**

![Focus Keyword-Gutenberg ](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20608%20976'%3E%3C/svg%3E)

**Note:**It is also possible to automate the insertion of your focus keywords, [learn more about that here.](https://rankmath.com/kb/how-to-automate-the-insertion-of-focus-keyword/)

## 2  Using the WordPress Classic Editor

To add SEO metadata in Classic Editor, navigate to your post editing screen. Then scroll down a bit to locate the Rank Math SEO settings.

### 2.1  Add SEO Meta Title in Classic Editor

In Rank Math SEO **General Tab** you can change your SEO title in the **Title**section as shown below:

![Add SEO Title in Classic Editor](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201930%20870'%3E%3C/svg%3E)

### 2.2  Add Meta Description in Classic Editor

You can enter your meta description in the Rank Math SEO**General Tab** → **Description** section of your post.

![Meta Description in Classic Editor](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201832%201116'%3E%3C/svg%3E)

### 2.3  Add Focus Keyword in Classic Editor

You can set the focus keyword in the**General tab → Focus Keyword**in the Rank Math SEO.

![Focus Keyword- Classic Editor](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201838%20272'%3E%3C/svg%3E)

## 3  Using the Elementor Site Builder

To add SEO metadata with Elementor Site Builder, open the post/page you want to edit with Elementor page builder. Then, click on the **SEO** Tab.

![SEO Tab in Elementor Page builder](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20644%20525'%3E%3C/svg%3E)

### 3.1  Add SEO Meta Title in Elementor

You can add SEO meta title in Elementor in the General tab of Rank Math. Click on **Edit Snippet** as shown below:

![Edit Snippet in Elementor](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20635%20554'%3E%3C/svg%3E)

Once you click on Edit Snippet a new window will open up and you can set your title in the **Title**section.

![Add Title- Elementor ](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201266%20768'%3E%3C/svg%3E)

### 3.2  Add Description in Elementor

To add a description in Elementor, navigate to the General tab of Rank Math, click on **Edit Snippet**, and enter the description in the **Description** section as shown below:

![Description in Elementor](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201308%201384'%3E%3C/svg%3E)

### 3.3  Focus Keyword in Elementor

You can add the focus keyword in Elementor in the **SEO tab →  General Settings → Focus Keyword.**

![Focus Keyword - Elementor](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20664%20976'%3E%3C/svg%3E)

## 4  Using the Divi Builder

To pull up your post or page’s SEO settings using the Divi builder, click on the **Rank Math SEO icon** to adjust the SEO settings for the page. It resides next to the Divi Settings icon, as shown below:

![Click on Rank Math icon](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201652%201292'%3E%3C/svg%3E)

### 4.1  Add SEO Meta Title in Divi Builder

To add SEO title in the Divi Builder click on **Edit Snippet** in the Rank Math General tab as shown below:

![Add SEO title in Divi Builder](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201758%201106'%3E%3C/svg%3E)

Once you click on Edit Snippet, a new window will show up where you can set the title in the **Title**section.

![Enter your SEO Title](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201284%201312'%3E%3C/svg%3E)

### 4.2  Add Description in Divi Builder

To add the description in the Divi builder, click on **Edit Snippet**in the**General tab** of Rank Math. Enter the description in the **Description**box as shown below:

![Add description in Divi builder](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201266%201300'%3E%3C/svg%3E)

### 4.3  Add Focus Keyword in Divi Builder

To set the focus keyword, navigate to the **General tab** in Rank Math SEO and enter the focus keyword in the **Focus Keyword** section as shown below:

![Add focus keyword in Divi](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20792%201116'%3E%3C/svg%3E)

## 5  Frequently Asked Questions

### Why Does Every Word Start With Big Letters in the Meta Title?

If every word in the meta title starts with a capital letter, you’ve likely enabled the ‘Capitalize Titles’ option. To deactivate it, navigate to **WordPress Dashboard → Rank Math SEO → Titles & Meta → Global Meta** and disable **Capitalize Titles**. Once done, scroll down and click **Save Changes**.
