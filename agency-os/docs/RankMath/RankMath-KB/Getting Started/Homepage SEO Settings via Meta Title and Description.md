# Homepage SEO Settings via Meta Title and Description

			
			

	

You can easily set the Meta Title and Description of the homepage with the help of [Rank Math](https://rankmath.com/wordpress/plugin/seo-suite/). In this knowledgebase article, we’re going to walk you through how to set your homepage meta title and description.

Let’s take a look at exactly how to do this:

![How to Change Your Homepage's Meta Title and Description - Rank Math SEO](https://img.youtube.com/vi/r5KqEfiQ7HE/maxresdefault.jpg)
__

Given that there are many ways to edit your homepage Meta Title and Description with Rank Math, at first, you’ll need to identify if your homepage is set to display posts or a static page. You can find this out by navigating to **WordPress Dashboard →** **Settings → Reading → Your Homepage displays**.

![Your homepage displays](https://rankmath.com/wp-content/uploads/2021/05/Your-Homepage-displays.jpg)

  
## Based on What Your Homepage Displays

## 1  Edit Your Titles & Meta Settings

If your homepage is set to display the latest posts, then to set the Meta Title and Description of your homepage, navigate to the **Homepage** settings, which is located under **Rank Math SEO → Titles & Meta**as shown below:

![Homepage Titles & Meta settings](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201200%20484'%3E%3C/svg%3E)

You can then enter your Homepage Title in the **Homepage Title** section and use the [various variables available](https://rankmath.com/kb/variables-in-seo-title-description/) in the drop-down list.

![Homepage Title](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201592%201036'%3E%3C/svg%3E)

Below is an example of what the output would look like if you use the `sitename` variable when the site name is “Rank Math”:

![Homepage Title for Rank Math](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201554%20442'%3E%3C/svg%3E)

You can enter your Homepage description in the Homepage Meta Description section. In addition, you can make use of the variables from the drop-down list.

![Homepage Meta Description](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%202028%201224'%3E%3C/svg%3E)

The below example shows the description of Rank Math:

![Example- Meta Description](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201556%20418'%3E%3C/svg%3E)

## 2  Edit Your Homepage Directly

If you’ve set a specific page as your homepage under **WordPress Dashboard → Settings → General → Your homepage displays**, then you can edit the page directly from **Rank Math SEO → Titles & Meta → Homepage**, as shown below:

![Edit Homepage](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201986%20841'%3E%3C/svg%3E)

### 2.1  Using the Gutenberg Editor

Once you click the **Edit Page**, you’ll be redirected to the regular edit screen for pages in WordPress, where you can use Rank Math in the sidebar in the Gutenberg Block editor.

![Edit Snippet](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201138%20888'%3E%3C/svg%3E)

Click the **Edit Snippet** button. And in the snippet editor, you can add a Meta Title and Description for your homepage.

![Title and Meta Description in Gutenberg](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201263%201454'%3E%3C/svg%3E)

### 2.2  Using the Classic Editor

If you’re using **Classic Editor**, scroll down the page to use the Classic Editor’s Meta Box.

![Edit snippet in Classic Editor](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20813%20300'%3E%3C/svg%3E)

Click the **Edit Snippet** button. And in the snippet editor, you can add a Meta Title and Description for your homepage.

![Homepage title and description in Classic Editor](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201265%201475'%3E%3C/svg%3E)

### 2.3  Using the Elementor Site Builder

If you’re using Elementor, you can use Rank Math available in the sidebar of Elementor.

![Homepage - SEO Title & Description - Elementor](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20588%20644'%3E%3C/svg%3E)

Click the **Edit Snippet** button located in the SEO tab. And in the snippet editor, you can add a Meta Title and Description for your homepage.

![Add Title and Description in Elementor](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201272%201328'%3E%3C/svg%3E)

Once you’ve added the Meta Title and Description in the snippet editor, click the **Update** button to save the changes.

### 2.4  Using the Divi Builder

To pull up your post or page’s SEO settings using the Divi builder, click on the **Rank Math SEO icon** to adjust the SEO settings for the page.

![Click on Rank Math icon in Divi Builder](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%202182%201138'%3E%3C/svg%3E)

Click the **Edit Snippet** button as shown below:

![Edit Snippet in Divi Builder](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201908%201300'%3E%3C/svg%3E)

And in the snippet editor, you can add a Meta Title and Description for your homepage.

![Homepage - SEO Title & Description - Divi](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%202560%201321'%3E%3C/svg%3E)

Once you’ve added the Meta Title and Description in the snippet editor, update the page to save the changes.

Now you can find the changes made to the title and description reflected in the source code of your homepage as well. However, it would take a while for the changes to [get updated in the search engine](https://rankmath.com/kb/google-index/).

And, that’s it! If you still have any questions on setting the Meta Title and Description for your homepage with Rank Math, [feel free to reach our support team](https://rankmath.com/support/) — we’re always here to help.
