# How to Switch From Easy to Advanced Mode

			
			

	

Rank Math has got an Easy mode to benefit beginners who want to let Rank Math do all the heavy lifting SEO work following the best practices. The Advanced mode is available for users who wish to have full control over their website’s SEO.

And many options are available only when you enable the Advanced Mode in Rank Math. We’ve got a [dedicated KB on Advanced Mode](https://rankmath.com/kb/advanced-mode/) to help you understand the options and modules that are available only in Advanced Mode.

Rank Math allows you to switch between the modes, and in this knowledgebase article, we’ll walk you through how you can switch from Easy mode to Advanced mode.

## 1  Using Setup Wizard

The Setup Wizard gets initiated automatically when you install Rank Math for the very first time. Or when you [access Setup Wizard](https://rankmath.com/kb/how-to-access-setup-wizard/) from **WordPress Dashboard → Rank Math SEO → Dashboard → Setup Wizard**. We give you an option here to choose a mode between the two.

![Setup Wizard ](https://rankmath.com/wp-content/uploads/2021/01/advacned-mode-rank-math.jpg)

## 2  Using Rank Math Dashboard

If you haven’t changed the mode during the Setup Wizard, you need not worry, as you can switch between modes at any time from the top-right corner at **WordPress Dashboard → Rank Math SEO → Dashboard.**

![Advanced mode](https://rankmath.com/wp-content/uploads/2023/01/advanced-mode-6-scaled.jpg)

And, that’s it! Once you’ve switched to Advanced Mode, you’ll be able to access all of the functionality, including the more complex settings that are hidden for simplicity when the plugin is set to Easy Mode. If you still have any questions on switching modes with Rank Math, feel free to [reach our support team](https://rankmath.com/support/), as we’re always here to help.
