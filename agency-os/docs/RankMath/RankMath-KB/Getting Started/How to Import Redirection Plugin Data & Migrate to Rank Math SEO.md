# How to Import Redirection Plugin  Data & Migrate to Rank Math SEO

			
			

	

Rank Math lets you import data easily from the Redirection plugin and ensures that all your existing redirections are in place after the migration. In this knowledgebase article, we’ll discuss how you can import the data from the [Redirection plugin](https://wordpress.org/plugins/redirection/) into Rank Math SEO.

Reducing the number of additional plugins on your site is a great way to simplify your codebase, and you can reduce the risk of running into issues, especially with a development team with a strong reputation and a [support team](https://support.rankmath.com) to help in the unlikely event of any issues.

So, without further ado – here’s how to migrate from the Redirection WordPress plugin to Rank Math:

## Importing Redirection Plugin Data Using Setup Wizard

You can import your redirections from the Redirection plugin to the Rank Math SEO plugin while running through the Setup Wizard, as shown below.

### 1  Open Rank Math Setup Wizard

The Setup Wizard will be initiated automatically when you install Rank Math for the first time. If for some reason, the Setup Wizard doesn’t start on its own, you can always start it from **WordPress Dashboard → Rank Math SEO →** **Dashboard → Setup Wizard**.

![Open Rank Math Setup Wizard](https://rankmath.com/wp-content/uploads/2023/01/setup-wizard.jpg)

### 2  Navigate to Import Section

The Rank Math Setup Wizard will look like this. You can click the **Start Wizard** button to proceed to the Import section, where we’ll be importing the redirections.

![Start Wizard](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%202560%201975'%3E%3C/svg%3E)

### 3  Import Data from Redirection Plugin

In the Import SEO Settings section, you can find Rank Math has detected redirections created with the Redirection plugin.

Ensure the **Import Redirections** checkbox is selected, and now you can click the **Start Import** button.

![Click Start Import for Redirections](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20957%20583'%3E%3C/svg%3E)

Rank Math will now start to import your redirections, and you’ll need to wait until the process gets completed.

![Importing redirections complete](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201550%20688'%3E%3C/svg%3E)

Once the redirections are imported, you can click **Continue** to proceed with the remaining steps in the Setup Wizard. You can refer to our dedicated KB to configure all the [settings available in the Setup Wizard](https://rankmath.com/kb/how-to-setup/).

## Importing Redirection Plugin Using Rank Math Import & Export

In case, if you’ve not imported your redirections while setting up Rank Math, you can always do that with the Import & Export feature of Rank Math. To use this feature,

### 1  Open Import & Export

At first head over to **Rank Math SEO → Status & Tools** from your WordPress dashboard. In the Status & Tools dashboard, click on **Import & Export** tab (_available only in the [Advanced Mode](https://rankmath.com/kb/switch-from-easy-to-advanced-mode/)_).

![Import Export tab](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%202476%201198'%3E%3C/svg%3E)

### 2  Choose Redirection Data to Import

Scroll down a bit, and you’ll find the **Other Plugins** section. Here you can find a tab for the Redirection Plugin. Under the Redirections tab, ensure that the **Import Redirections** checkbox is selected as shown below.

![Other Plugins](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%202088%20714'%3E%3C/svg%3E)

### 3  Import Data

Click on **Import**. A small message will be displayed on the screen that asks for your confirmation to import the settings. Click on **OK**.

![Confirmation Message](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20870%20276'%3E%3C/svg%3E)

The import will then start, and, in a matter of seconds, all your data will be successfully imported to Rank Math SEO.

Now you can check all your redirections at **Rank Math SEO → Redirections** inside your WordPress dashboard. If the Redirections menu is unavailable under Rank Math, ensure that you’ve enabled the Redirections module under **WordPress dashboard → Rank Math SEO → Dashboard → Modules**.

And, that’s it! We hope the tutorial was helpful in importing the data from the Redirection plugin. If you have absolutely any questions about moving over to Rank Math & getting started – feel free to [reach our support team directly from here](https://rankmath.com/support/), and we’re always here to help.
