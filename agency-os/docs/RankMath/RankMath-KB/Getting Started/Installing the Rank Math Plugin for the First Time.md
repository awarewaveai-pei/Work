# Installing the Rank Math Plugin for the First Time

			
			

	
Your SEO workflow is about to get a lot smoother. Of course, the first step is to install the Rank Math plugin and set it up.

We’ve made the installation process as smooth as possible with a step-by-step setup wizard. The wizard is there to help you configure the plugin for your site – there are lots of options to choose from, and each type of site has its own requirements.

In this article, we’re going to guide you through the process of installing the plugin and working through the wizard. We’ll explain what the different options mean and guide you to make the right choices for your site.

Of course, you can change the settings later through the plugin’s interface – so it’s not the end of the world if you make a mistake the first time.

But first, let’s add the plugin to your site. The process is exactly the same as any WordPress plugin – there are several ways you can install it. You can:

- [Upload it through the wp-admin panel](https://rankmath.com/kb/installing-through-the-admin-panel/)

- [Upload it to the server using FTP](https://rankmath.com/kb/installing-with-ftp/)

- [Download it directly onto the server using SSH](https://rankmath.com/kb/installing-with-ssh/)

The first option is the easiest method, while the third option is more advanced – if you’re unfamiliar with SSH and the wget command, you should use the wp-admin panel. If that fails (due to your server settings), use the FTP installation method.

## Activating Rank Math

With most WordPress plugins, activation is as simple as clicking on a link. Rank Math is a very sophisticated plugin with dozens of settings and options, so we’ve designed a quick set-up wizard to get the right settings for your site.

Rank Math can also import the settings from another SEO plugin – such as the Yoast SEO plugin. So, if you’ve used one of the supported plugins in the past, you can save time by importing these settings.

Check out this article for [step-by-step setup instructions](https://rankmath.com/kb/how-to-setup/#step-1-import-data).

## Next Steps

Great, you’ve installed Rank Math! And you’ve already configured the plugin to your own specific needs. There are more refinements that you can make – Rank Math’s admin interface has dozens of extra settings you haven’t seen yet. And you can always change the settings you’ve made during installation.

In the next articles, we’ll show you how to use Rank Math for higher rankings when you publish content. And we’ll cover all the [features and advanced settings in-depth](https://rankmath.com/kb/general-settings/).
