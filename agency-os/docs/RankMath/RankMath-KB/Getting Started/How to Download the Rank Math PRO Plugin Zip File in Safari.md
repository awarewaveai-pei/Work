# How to Download the Rank Math PRO Plugin Zip File in Safari

			
			

	

In this knowledgebase article, we’re going to walk you through how to download the zip file of Rank Math PRO. So let’s get started.

![Rank Math PRO Installation & Activation](https://img.youtube.com/vi/nCDe67K_3rA/maxresdefault.jpg)
__

## Table of Contents

- [Download Rank Math PRO Version](#download)

- [Compress Rank Math PRO Folder](#compress)

- [Navigate to Preferences](#navigate-to-preferences)

- [Uncheck Open ‘safe’ files after downloading Option](#uncheck-open-safe-files)

## 1  Download Rank Math PRO Version

To begin with, open Safari on your Mac. Navigate to the Rank Math website and download the PRO version from your [account](https://rankmath.com/my-account/).

![download Rank Math pro version](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%202560%201472'%3E%3C/svg%3E)

## 2  Compress Rank Math PRO Folder

Compress the Rank Math PRO folder. It will then compress the seo-by-rank-math-pro folder. When you download a zip in Safari, the browser automatically extracts the zip and then deletes the zip file.

![Compress Rank Math folder](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20754%20508'%3E%3C/svg%3E)

## 3  Navigate to Preferences

Navigate to **Safari → Preferences** as shown below:

![Preferences](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201658%201160'%3E%3C/svg%3E)

## 4  Uncheck **Open ‘safe’ files after downloading** Option

Navigate to the **General Tab** and uncheck the**Open ‘safe’ files after downloading** option as shown below:

![Uncheck 'safe' files option](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%202366%201172'%3E%3C/svg%3E)

You can now locate the seo-by-rankmath-pro in the downloads section.

![PRO version downloaded](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%202560%20857'%3E%3C/svg%3E)

And that’s it – if you have absolutely any questions about getting started with Rank Math PRO, please [refer to our knowledgebase](https://rankmath.com/kb/) or [reach out to our support team](https://rankmath.com/support/).
