# Migrating from SEOPress to Rank Math SEO

			
			

	

Migrating from SEOPress to Rank Math SEO is a lot easier, and we ensure that your post SEO metadata gets migrated carefully so that you don’t lose anything in the process and don’t have to configure all your SEO metadata once again.

In this knowledgebase article, we’ll discuss how you can import the data from SEOPress and SEOPress Pro into Rank Math SEO.

Note: We recommend backing up your site before you begin the migration process.

## 1  Using Rank Math Setup Wizard

You can import data from the SEOPress plugin to the Rank Math SEO plugin right away with our Setup Wizard by following the exact steps shown below.

### 1.1  Open Rank Math Setup Wizard

When you [install the Rank Math](https://rankmath.com/kb/how-to-setup/) plugin for the first time, the Setup Wizard will get initiated automatically. In case, if the Setup Wizard doesn’t start on its own, you can always start it from **WordPress Dashboard → Rank Math SEO →** **Dashboard → Setup Wizard**.

![Access Rank Math Setup Wizard](https://rankmath.com/wp-content/uploads/2022/10/setup-wizard-2.jpg)

The Setup Wizard will look like this:

![Setup wizard](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%202560%201975'%3E%3C/svg%3E)

### 1.2  Deactivate SEOPress Plugin

When you scroll down the page a little bit, you can notice the Rank Math running compatibility tests to identify any conflicting plugins. Click the **More** button to see if there are any conflicting SEO plugins installed on your website.

![Deactivate SEOPress plugin](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201660%20257'%3E%3C/svg%3E)

If SEOPress has been installed on your website, you can safely deactivate the plugin from here — so that you won’t end up over-optimizing your website for search engines. We will import the data from the SEOPress plugin in the next step.

### 1.3  Start Setup Wizard

Once you’ve deactivated the plugin, click the **Start Wizard** button.

![Start wizard to setup Rank Math](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201863%20490'%3E%3C/svg%3E)

### 1.4  Import Data from SEOPress

In the next step, you can find the input data available from the SEOPress plugin — we recommend selecting all the data so that you don’t lose anything in this migration process.

You can also choose to recalculate SEO scores along with. However, please note, **this method will only update the SEO score of posts set as N/A**. Click the **Start Import** button, and within a few seconds, Rank Math will start importing your data.

![Input available from SEOPress to import](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201930%201202'%3E%3C/svg%3E)

You can check the status at the progress bar. Once your data is imported successfully, you can click **Continue** to proceed with the next step. You can refer to our [detailed tutorial on our Setup Wizard](https://rankmath.com/kb/how-to-setup/) for configuring the other settings available in the Setup Wizard.

![Importing data from SEOPress completed](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201526%20690'%3E%3C/svg%3E)

## 2  Using Rank Math Import & Export

If you’ve skipped or missed importing data from the SEOPress plugin during the Setup Wizard — no issues, you can always import your data with the Rank Math Import & Export feature.

### 2.1  Open Import & Export

At first head over to **Rank Math SEO →** **Status & Tools** as shown below:

![Click on Status & Tools](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20618%20740'%3E%3C/svg%3E)

In the Status & Tools dashboard click on **Import & Export** tab.

![Click on Import & Export](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%202124%20552'%3E%3C/svg%3E)

### 2.2  Choose Data to Import

Scroll down a bit and you’ll find the **Other Plugins** section. You can find the SEOPress tab here. Under the SEOPress tab, you can choose all the data to be imported from the SEOPress plugin.

![Locate SEOPress in Other Plugins](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%202114%20854'%3E%3C/svg%3E)

### 2.3  Import Data

Click on **Import**. A small message will be displayed on the screen that asks for your confirmation to import the settings. Click on **OK**.

![Click on Ok](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20861%20196'%3E%3C/svg%3E)

The import will then start within a few seconds and all your data will be successfully imported to Rank Math SEO.

And, that’s it! We hope the tutorial was helpful in migrating from SEOPress to Rank Math. If you have absolutely any questions about moving over to Rank Math & getting started – feel free to [reach out to our support team directly from here](https://rankmath.com/support/), and we’re always here to help.
