## 1  Creating a Product Description

Let us now see how to create a product description using our [Content AI](https://rankmath.com/kb/how-to-use-content-ai/) module.

### 1.1  Enable the Content AI Module

The first step is to head over to **Rank Math SEO → Dashboard → Modules** from your WordPress dashboard. Here, scroll down to find the **Content AI**module and enable it as shown below if you haven’t already.

![Enable Content AI module](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%202160%20710'%3E%3C/svg%3E)

**Note:** If you exhaust your feature usage limits, you can easily upgrade to a higher [Content AI plan](https://rankmath.com/content-ai/) that aligns with your requirements.

### 1.2  Select the Product Description AI Tool

Next, head over to **Rank Math SEO → Content AI → Content Editor**, as shown below.

![Navigate to Content Editor](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%202560%20800'%3E%3C/svg%3E)

In the Content Editor, click **AI Tools** and select **Product Description**. Alternatively, you can choose the Product Description AI tool from your favourite WordPress Editors or from the AI Tools tab, whichever suits your writing flow.

![Click Product Description](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%202492%201222'%3E%3C/svg%3E)

You will be presented with the Product Description AI tool settings. Let’s discuss each of these fields one by one.

## 2  Available Options in the Product Description AI Tool

We’ll now discuss each option in the Product Description tool in detail.

### 2.1  Product Name

In 200 characters or less, enter the product’s name exactly as you want it to appear in the description. This is a required field.

![Product Name](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20956%20195'%3E%3C/svg%3E)

### 2.2  Features and Benefits

In 600 characters or less, enter the characteristics of the products, along with the problems it will solve for the user or the advantages the user will derive from using it.

The features include things like its color, origin, and construction material. The benefits explain how the features solve a problem or work to the advantage of the user. For example, a thick coat will keep the wearer warm even in the coldest winter.

**Note:**You can generate your features and benefits with the [Topic Research AI tool](https://rankmath.com/kb/content-ai-topic-research-tool/). Enter your product name followed by ‘features and benefits’ as the **Topic** and set the **Format**to ‘List.’ E.g., iPhone 14 features and benefits.

![Features and Benefits](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20958%20363'%3E%3C/svg%3E)

### 2.3  Audience

Select the option that best describes your target audience in this field. You can type in the word or select from the dropdown menu. You can enter multiple audiences.

[See the full list of all the Audience options we offer ➜](https://rankmath.com/kb/configure-content-ai-global-settings/#audience)

![Select Audience](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201181%20988'%3E%3C/svg%3E)

### 2.4  Focus Keyword

Enter your primary focus keyword, followed by any other keyword you want to rank for in this field. The keywords should be at most 200 characters. Remember to separate multiple keywords with a comma.

![Focus Keyword](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20963%20205'%3E%3C/svg%3E)

### 2.5  Tone

Select the tone in which you want the product description to be written. You can select multiple tones here.

[See the full list of all the Tone options we offer ➜](https://rankmath.com/blog/tone-in-writing/)

![Select Tone](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201162%20927'%3E%3C/svg%3E)

### 2.6  Output Language

Next, select the output language in which you want the produce description to be generated. You can only choose one language there.

[See the full list of all the Output Language options we offer ➜](https://rankmath.com/kb/configure-content-ai-global-settings/#languages)

![Select Output Language](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201870%201310'%3E%3C/svg%3E)

### 2.7  Number of Outputs

Enter a number between one and five in the Number of Outputs field.

![Number of Outputs](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20815%20123'%3E%3C/svg%3E)

### 2.8  Generate

After filling in the required fields, you will click **Generate**. Content AI will generate your product description within a few seconds.

![Generate product description](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201904%201250'%3E%3C/svg%3E)

If you want Content AI to create more product descriptions, click **Generate More**.

### 2.9  Insert

Hover over a description you are interested in and click **Insert**, as shown below. The description will be inserted into the Content Editor. You can further develop it using the other AI tools in Content AI.

![Insert Product Description](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201888%201246'%3E%3C/svg%3E)

## 3  Use Cases for the Product Description AI Tool

The Product Description AI tool is designed to help businesses create compelling and persuasive product descriptions that captivate potential customers. Below are some practical use cases for this tool:

### 3.1  E-commerce Product Descriptions

A well-crafted product description is crucial for e-commerce success. This tool helps you quickly generate product descriptions that clearly explain the product’s features and benefits, tailored to your target audience.

Whether you sell clothing, gadgets, or beauty products, the AI will create descriptions that drive conversions.

![Writing ecommerce product descriptions with Content AI](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201179%20851'%3E%3C/svg%3E)

### 3.2  Descriptions for Digital Products

Digital products like eBooks, courses, or software require detailed descriptions that explain their value and features. This AI tool helps create descriptions that highlight the key features of the digital product while also emphasizing its relevance and benefit to the buyer.

![writing digital product descriptions with Content AI](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201180%20850'%3E%3C/svg%3E)

### 3.3  Product Descriptions Tailored for Niche Markets

When targeting a specific niche market, your product descriptions need to speak directly to that audience’s unique needs and interests.

This tool allows you to generate highly targeted product descriptions that resonate with niche audiences, such as eco-conscious consumers, fitness enthusiasts, or pet owners.

![create product descriptions for niche markets with Content AI](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201173%20848'%3E%3C/svg%3E)

### 3.4  Descriptions for Seasonal Products

Seasonal products require descriptions that highlight their time-sensitive appeal. Whether it’s a holiday-themed item or a summer-specific product, this tool can help you craft descriptions that draw attention to the seasonal relevance and the benefits of buying now before the opportunity is gone.

![Write seasonal product descriptions with Content AI](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201178%20847'%3E%3C/svg%3E)
