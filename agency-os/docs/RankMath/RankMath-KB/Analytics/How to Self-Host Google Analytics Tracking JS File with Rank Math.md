# How to Self-Host Google Analytics Tracking JS File with Rank Math

			
			

	

In this knowledgebase article, we’re going to walk you through how to self-host the Google Analytics tracking JavaScript file.

## How to Self-Host Google Analytics Tracking JS File [PRO](https://rankmath.com/pricing/)

## Table of Contents

- [Enable the Analytics Module](#analytics-module)

- [Connect Your Google Account](#connect-google-account)

- [Enable Self-Hosted Analytics JS File Option](#js-file)

### 1  Enable the Analytics Module

To begin with, ensure that you’ve enabled the [Analytics module](https://rankmath.com/kb/analytics/) by navigating to **Rank Math SEO → Dashboard**as shown below.

![Enable Analytics module](https://rankmath.com/wp-content/uploads/2023/01/enable-analytics-module-2-scaled.jpg)

### 2  Connect Your Google Account

The next step is to [connect your Google account.](https://rankmath.com/kb/connect-your-google-account/) If you’re doing this for the very first time, we recommend you read our tutorial on [how to install Google Analytics](https://rankmath.com/kb/install-google-analytics/) with Rank Math SEO.

Once you’ve connected Google Analytics, enable the **Install analytics code option**which you’ll find in Rank Math’s General Settings which are located under **Rank Math SEO → General Settings → Analytics**, as shown below:

![Enable Install Analytics code](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20960%20358'%3E%3C/svg%3E)

Once enabled, the additional options shown above will appear allowing you to choose whether you’d like to [anonymize IP addresses](https://rankmath.com/kb/anonymize-ip-addresses-google-analytics/), and self-host the Google Analytics tracking JavaScript file.

### 3  Enable Self-Hosted Analytics JS File Option

Enable the Self-Hosted Analytics JS File option. When enabled, Rank Math will host the Google Analytics tracking file locally (automatically updating the script every 12 hours), which can help accelerate the speed of your website as an external request no longer needs to be made.

![Enable Self-hosted Analytics JS file](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20993%20356'%3E%3C/svg%3E)

If you still have any questions about self-hosting your Google Analytics tracking file, please feel free to [reach out to our support team](https://rankmath.com/support/) who are always more than happy to help.
