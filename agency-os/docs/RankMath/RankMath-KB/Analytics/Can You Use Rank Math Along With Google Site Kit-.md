# Can You Use Rank Math Along With Google Site Kit?

			
			

	

Site Kit is Google’s official WordPress plugin that lets you integrate your WordPress website with Google services such as — Google Search Console, Analytics, AdSense, PageSpeed Insights, [Tag Manager](https://rankmath.com/blog/install-google-tag-manager/), and Optimize.

In this knowledgebase article, we’ll discuss if you can use Rank Math along with [Google Site Kit plugin](https://wordpress.org/plugins/google-site-kit/).

## Using Rank Math Over Google Site Kit

We wouldn’t recommend using both Rank Math and Google Site Kit in parallel for the following reasons:

### 1  Features Overlap

Rank Math includes a number of features that overlap with what Google Site Kit offers. Rank Math also allows you to integrate your website with Google account services like Google Search Console, Analytics, AdSense, and PageSpeed score within a matter of a few clicks.

The dedicated Analytics module of Rank Math can be configured under **Rank Math SEO →** **General Settings → Analytics**. Here is a [detailed tutorial](https://rankmath.com/kb/connect-your-google-account/) that would guide you through the configuration.

![Analytics settings](https://rankmath.com/wp-content/uploads/2023/06/analytics-settings-rank-math-1-scaled.jpg)

In addition to that, Rank Math keeps you informed of your website’s stats through [Analytics Dashboard](https://rankmath.com/kb/analytics/), [Email Reports](https://rankmath.com/kb/seo-email-reporting/), and [Client Management](https://rankmath.com/kb/client-management/) dashboard.

![Rank Math Analytics Dashboard](https://rankmath.com/wp-content/uploads/2022/03/image-79.png)

As a matter of fact, Rank Math is the only SEO plugin integrated well with the [Google Search timeline](https://rankmath.com/google-updates/) so that you can check how well your site has performed with respect to algorithm changes right inside your WordPress dashboard and helps you take action to optimize your website’s SEO further, whenever required.

![Google search update in Rank Math](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201200%20661'%3E%3C/svg%3E)

### 2  Limiting Number of Active Plugins

Having multiple plugins for the same set of tasks will certainly have an impact on how fast your website loads. It is why we always recommend [not to use more than one SEO plugin](https://rankmath.com/kb/keep-only-one-seo-plugin-active/) on a website.

Rank Math is already one of the fastest SEO plugins and includes similar features that Site Kit offers; hence, we’d suggest limiting the number of plugins installed on your website and prefer the more optimized solution in this case.

### 3  Plugin Conflict

Since Rank Math and Site Kit have similar features, they tend to target the same code functionalities on your website. It might lead to duplicate queries, as they will require data from your site’s Google Search Console & Analytics property, which might lead to plugin conflicts.

However, if you’re still looking to use Google Site Kit along with Rank Math — you can still do that. As you know, Rank Math is built on a [modular approach](https://rankmath.com/kb/managing-modules/); you can disable the Analytics module, the entire set of Rank Math’s Analytics code will not be executed, and you can avoid any possible plugin conflict.

And that’s it! If you still have absolutely any questions about using Rank Math, please feel free to [reach our support team directly from here](https://rankmath.com/support/), and we’re always here to help.
