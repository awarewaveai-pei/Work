# How to Find Rank Math’s Unique Entity ID

			
			

	

As a business owner, you’ll have to deal with regulations like paying federal and state taxes, filing an annual report or other documentation, and adhering to local zoning & permitting laws to continue doing business.

For any such uses, if you need the Unique Entity of Rank Math, we’ll show you how to get it with this Knowledge Base article.

## Rank Math’s Unique Entity ID

The Unique Entity ID is a 12-character alphanumeric ID assigned to an entity by SAM.gov.

FastSpring is our authorized reseller and is an entity registered with the System for Award Management (SAM) of the U.S. General Services Administration (GSA).

**You can use FastSpring’s unique entity ID, which you can find [here](https://opengovus.com/sam-entity/849108811).**
