# Exclude Sitemap From Hummingbird Cache

			
			

	

[Hummingbird](https://wordpress.org/plugins/hummingbird-performance/) is a WordPress speed optimization plugin. The design and the features of this plain are simple, and it gets the job done without much fuss. So, as you’d expect, excluding your sitemap from Hummingbird’s caching is very simple.

In this knowledgebase article, we’re going to walk you through how to exclude the sitemap from the Hummingbird plugin’s cache.

## 1  Navigate to Caching in Hummingbird

To begin with, navigate to **Caching** located under **Hummingbird Settings**as shown below:

![Hummingbird Settings](https://rankmath.com/wp-content/uploads/2023/04/hummingbird-caching.jpg)

## 2  Navigate to Page Caching Tab

Select the **Page Caching** tab and click on **Activate** as shown below:

![Select Page Caching](https://rankmath.com/wp-content/uploads/2023/04/page-caching.jpg)

## 3  Navigate to the Exclusions Option

Then head over to the **Exclusions** option. There should already be an entry for sitemap.xml, but if it is not there or the file is named differently, you should add that name here as well.

![Exclusions](https://rankmath.com/wp-content/uploads/2023/04/url-strings.jpg)

Once you have made the changes click on **Save Settings.**

And that’s it! Your sitemap will now be excluded from Hummingbird Cache. If you’re still having any issues, please feel free to [reach our support team](https://rankmath.com/support/) directly from here.
