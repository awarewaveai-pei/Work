# How to Use the Local Business Block in Multiple Locations CPT

			
			

	

In this knowledgebase article, we’re going to walk you through how to use Rank Math’s Local Business block in the [multiple locations](https://rankmath.com/kb/multiple-locations/) post type.

To get started, you’ll need to have [created multiple locations](https://rankmath.com/kb/multiple-locations/) using Rank Math. You can refer to our dedicated guide on [Local SEO](https://rankmath.com/kb/local-seo/) to create new locations and display your business and local information on the frontend of your website.

Once you’ve added multiple locations then use Rank Math’s Local Business Block as shown below. If you don’t see the block in the multiple locations post type, then check if you’ve enabled the Schema module under **Rank Math SEO > Dashboard > Modules**.

![Local Business Block by Rank Math](https://rankmath.com/wp-content/uploads/2021/02/local-business-block-1.jpg)

Let us now look at each setting that is present in the Local Business Block.

## Rank Math LocalBusiness Block Settings

### 1  Type

In the **Block settings > Type**, You can set the Address, Opening hours, Map, Store Locator for your location accordingly.

![Block Settings-Type](https://rankmath.com/wp-content/uploads/2021/02/type.jpg)

Let’s look at each of them in detail.

### 1.1  Address

When you select the type as an address, the address of the location will be displayed.

![Address](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20417'%3E%3C/svg%3E)

You’ll also notice some other options that’ll help you to display the information according to your choice.

![Other options in address](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20596%201172'%3E%3C/svg%3E)

#### 1.1.1  Show Company Name

Show Company Name will display the name of the company if it’s enabled.

![Show Company Name](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20417'%3E%3C/svg%3E)

#### 1.1.2  Show Address on One Line

Show address on one line option will display the address in a single line if it’s enabled.

![Show Address on One Line option](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20256'%3E%3C/svg%3E)

#### 1.1.3  Show State

Show State will display the name of the state if the option is enabled.

![Show State](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20300'%3E%3C/svg%3E)

#### 1.1.4  Show Country

Show Country option will display the name of the country if the option is enabled.

![Show Country](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20329'%3E%3C/svg%3E)

#### 1.1.5  Show Primary Number

Show Primary number option will display the primary number of your business if the option is enabled.

![Show Primary Number](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20305'%3E%3C/svg%3E)

#### 1.1.6  Show Secondary Number

Show Secondary number option will display the secondary number of your business if the option is enabled.

![Show Secondary number option](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20336'%3E%3C/svg%3E)

#### 1.1.7  Show FAX Number

Show FAX number option will display the FAX number of your business if the option is enabled.

![Show FAX number option](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20352'%3E%3C/svg%3E)

#### 1.1.8  Show Email

Show Email option will display the email address of your business if the option is enabled.

![Show Email](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20352'%3E%3C/svg%3E)

#### 1.1.9  Show Business URL

Show Business URL will display the URL of your business if the option is enabled.

![Show Business URL](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20325'%3E%3C/svg%3E)

#### 1.1.10  Show Logo

Show Logo option will display the logo of your business if the option is enabled.

![Show Logo](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20455'%3E%3C/svg%3E)

#### 1.1.11  Show VAT number

Show VAT number option will display the VAT ID if the option is enabled.

![Show VAT number option](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20292'%3E%3C/svg%3E)

#### 1.1.12  Show TAX ID

Show TAX ID option will display the Tax ID if the option is enabled.

Show COC number option will display the Chamber of Commerce ID if the option is enabled.

![Show COC number option](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20268'%3E%3C/svg%3E)

#### 1.1.14  Show Price Indication

Show Price Indication will display the price range of your business if the option is enabled.

![Show price indication option](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20295'%3E%3C/svg%3E)

### 1.2  Opening Hours

Opening hours will display the days and time when your business is open.

![Opening Hours ](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20298'%3E%3C/svg%3E)

Let’s look at the options available in the Opening hours:

#### 1.2.1  Enable/Disable the Days

You can select the days when your business is open or closed as shown below:

![Enable or disable the days](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20291'%3E%3C/svg%3E)

#### 1.2.2  Hide Closed Days

If you enable this option, the days when your business is closed will not be displayed. It will only display the Opening hours of your business.

![Hide Closed Days option](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20223'%3E%3C/svg%3E)

#### 1.2.3  Show Open Now Label After Opening Hour for Current Day

This option displays the ‘Open Now’ label after the opening hour for the current day.

![Show Open now label after opening hour for the current day](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20204'%3E%3C/svg%3E)

You can also change the label text as shown below:

![Change show open now label](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20234'%3E%3C/svg%3E)

### 1.3  Map

Map option let’s you display the location of your business on the map.

At first, you’ll have to create and enter the [Google Maps API Key.](https://developers.google.com/maps/documentation/javascript/get-api-key) Once you have created the key, paste it in **Rank Math > Titles & Meta > Google Maps API Key.**

![Map](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20373'%3E%3C/svg%3E)

This is how the map will be displayed:

![Map](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20460'%3E%3C/svg%3E)

#### 1.3.1  Map Type

You can select the map type from the options available.

![Select Map Type](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20588%20338'%3E%3C/svg%3E)

If you select the map type as RoadMap from the drop-down list, then a roadmap will be displayed and so on.

![Roadmap](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20456'%3E%3C/svg%3E)

#### 1.3.2  Map Width

Map Width option will let you set the width of the map.

![Map Width](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20601%20184'%3E%3C/svg%3E)

The map will reflect the changes as per the width that is set in this option.

![Width of the map](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20293'%3E%3C/svg%3E)

#### 1.3.3  Map Height

Map Height option will let you set the height of the map.

![Map Height](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20584%20156'%3E%3C/svg%3E)

This is how the map will look like:

![Height of the map](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20589'%3E%3C/svg%3E)

#### 1.3.4  Zoom Level

You can set the zoom level for the map with this option by increasing or decreasing the slider.

![Zoom Level option](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20582%20170'%3E%3C/svg%3E)

This is how the map will look like:

![Zoom Level](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20611'%3E%3C/svg%3E)

#### 1.3.5  Allow Zoom

You can either enable or disable this option if you wish or do not wish to zoom the map respectively.

![Allow Zoom option](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20418%20112'%3E%3C/svg%3E)

If enabled, you can zoom the map with the ‘+’ and ‘-‘ sign as shown below:

![Allow Zoom](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20494'%3E%3C/svg%3E)

#### 1.3.6  Allow Zoom by Scroll

This option allows to zoom the map by scrolling it. You can easily scroll the map if this option is enabled. If you do not wish to scroll the map then simply disable the option.

![Allow Zoom by scroll](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20526%20102'%3E%3C/svg%3E)

#### 1.3.7  Allow Dragging

This option allows you to drag the map. Either enable or disable the option to allow or disallow the dragging respectively.

![Allow Dragging option](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20401%20109'%3E%3C/svg%3E)

#### 1.3.8  Show Marker Clustering

You can either enable or disable this option if you wish or do not wish to show marker clustering on the map.

![Show Marker Clustering Option](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20482%20116'%3E%3C/svg%3E)

#### 1.3.9  Show Info Window

Show Info Window option displays the information of the location on the map if enabled. You can disable this option if you do not wish to display the information of your location on the map.

![Show Info Window Option](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20476%20144'%3E%3C/svg%3E)

This is how the map will display the locations information when the option is enabled:

![Show Info option enabled](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20566'%3E%3C/svg%3E)

### 1.4  Store Locator

The store locator settings will let you display and change the number of results that are shown in the store locator. You can also search within a given radius and look out for the nearest location if nothing is found within that given radius.

![Store Locator Settings](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20600%20878'%3E%3C/svg%3E)

### 2  Locations

You can choose the locations that you want to display from this option. You can also select **All Locations** from the drop-down list if you wish to display all the locations of your business .

![Locations Option](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20900%20320'%3E%3C/svg%3E)

### 3  Maximum Number of Locations to Show

This option lets you choose the number of locations that you want to display.

![Maximum Number of Locations to Show ](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20580%20169'%3E%3C/svg%3E)
