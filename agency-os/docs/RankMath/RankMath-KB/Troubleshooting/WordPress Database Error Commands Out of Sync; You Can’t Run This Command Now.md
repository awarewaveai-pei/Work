# WordPress Database Error Commands Out of Sync; You Can’t Run This Command Now

			
			

	

Some users may face **_WordPress database error Commands out of sync_** issues while using [WPML](https://rankmath.com/compatibility/wpml/), Shield, and a whole range of other plugins. In this knowledgebase article, we’ll discuss what causes this issue & how to deal with it.

## Why You May Experience the **_WordPress Database Error Commands out of Sync_** Error

Let’s look at the most common reasons for this error:

## Table of Contents

- [Caching Plugins](#caching-plugins)

- [Allowed Memory Size Exhausted](#memory-size)

- [A Theme or a Plugin Is Running a Query and Not Completing It](#theme-or-plugin-error)

### 1  Caching Plugins

You can check if the error is logged again by clearing/disabling the cache plugin and also on the server-side. Basically, it’s caused by when a plugin leaves a mess in database queries or does not close properly. You can try clearing the cache and see if it helps.

### 2  Allowed Memory Size Exhausted

If the log file is showing memory-related errors then this could be the reason for the error. Running a large database of products and especially importing them may make the database get out of sync.

### 3  A Theme or a Plugin Is Running a Query and Not Completing It

Another reason for this error could be that a theme or a plugin is running a query but it’s not completing it. In such a scenario, you can check if another plugin is not causing this problem by creating a staging site where you only active [Rank Math](https://rankmath.com/wordpress/plugin/seo-suite/). You may also try disabling the security plugins on your WordPress site and check whether that solves the issue.

And, if you’re still facing this issue, please feel free to [get in touch with our support team](https://rankmath.com/support/) – they’ll be more than happy to help you get to the bottom of the issue you’re experiencing.
