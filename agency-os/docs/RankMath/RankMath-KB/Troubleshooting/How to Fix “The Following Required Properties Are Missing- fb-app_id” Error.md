# How to Fix “The Following Required Properties Are Missing: fb:app_id” Error

			
			

	

In this knowledgebase article, we’ll discuss the error about a missing [Facebook App ID](https://developers.facebook.com/apps) “**The following required properties are missing: fb:app_id”**  that you might have come across.

![The following required properties are missing: fb:app_id](https://rankmath.com/wp-content/uploads/2021/10/The-following-required-properties-are-missing-fb-app-id-1.png)

‘**fb: app_ id**‘ tag can be added to your site’s header. It’s important to note that the issue of having this tag on your page doesn’t interfere with the ability to share posts on Facebook in any way.

You can ignore this warning but if you want to get rid of this error, then refer to the instructions below on how you can add it in WordPress using the [Rank Math SEO](https://rankmath.com/wordpress/plugin/seo-suite/) plugin:

**Note:** If you aren’t interested in creating a Facebook App, but wish to get rid of this error in the [Facebook Debugger tool](https://developers.facebook.com/tools/debug/), then you can simply use Facebook’s default App ID (_966242223397117_) and start from step 3 below.

## 1  Create Facebook App

At first, you need to [register as a Facebook developer](https://developers.facebook.com/docs/development/register). Once you’ve registered, you can create a Facebook App by [following this documentation](https://developers.facebook.com/docs/development/create-an-app).

When you create a Facebook App, a unique App ID will be generated.

## 2  Copy Facebook App ID

In your Facebook App Dashboard, you can copy your [Facebo](https://developers.facebook.com/apps)[ok App ID](https://developers.facebook.com/apps).

![Copy your App ID](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%20972%20636'%3E%3C/svg%3E)

## 3  Open Social Meta Settings

Then, head over to your **WordPress Dashboard → Rank Math SEO → Titles & Meta → Social Meta**as shown below:

![Rank Math Social Meta](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201156%20971'%3E%3C/svg%3E)

## 4  Enter Facebook App ID

In the Social Meta settings, you can fill out all the fields related to Facebook, particularly, enter your Facebook App ID in the **Facebook App** field, so that you can get rid of the error.

![Enter the Facebook App ID](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201540%20284'%3E%3C/svg%3E)

## 5  Save Changes

Now click on **Save Changes** at the bottom of the page. The Facebook App ID will now be added to your website’s code and hence the error should no longer be present.

![Save Changes](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201540%20207'%3E%3C/svg%3E)

## 6 Validate Using Facebook Debugger Tool

Then [clear your website cache & server cache](https://rankmath.com/blog/clear-cache-in-wordpress/) (_if any_) and then use the [Facebook Debugger tool](https://developers.facebook.com/tools/debug/) to confirm if the error is no longer present. You may need to click the **Scrape Again** to force the Debugger tool to fetch the latest version of your page.

![Click Scrape Again in Facebook Debugger tool](data:image/svg+xml,%3Csvg%20xmlns='http://www.w3.org/2000/svg'%20viewBox='0%200%201213%20576'%3E%3C/svg%3E)

And, that’s it! We hope the tutorial helped you get rid of the error.
