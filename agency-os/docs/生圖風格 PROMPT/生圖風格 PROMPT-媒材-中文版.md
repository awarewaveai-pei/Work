## 1. 水彩｜透明淡彩暈染風格

### 風格核心

水彩的風格核心是透明、流動、輕盈、暈染與紙本吸收感。它不是厚重覆蓋式繪畫，而是讓顏料與水在紙面上自然擴散、滲化、重疊，形成柔和而有呼吸感的畫面。這種風格適合表現清晨、霧氣、花卉、人物、自然風景、旅行速寫、詩意場景與安靜日常。

用於圖片生成時，重點不是單純把畫面變淡，而是要呈現「水分、紙張、透明層次與邊緣暈開」。主體可以清楚，但不應過度銳利；背景可以留白、淡化或自然流散，讓畫面保有空氣感與手繪感。

### 視覺特徵

畫面應有明顯的水彩紙肌理，能看到紙張纖維、顆粒、吸水痕、邊緣水漬與顏料沉澱。色彩不應像數位漸層般完美平滑，而應有自然濃淡、暈染邊界、局部水痕與顏料在紙面上沉積的痕跡。透明色層可以一層疊一層，暗部由多次罩染形成，而不是一次塗成厚重黑色。

主體邊緣應有「硬邊與軟邊並存」的效果。被仔細描繪的焦點，例如眼睛、花瓣、建築輪廓或物件邊緣，可以稍微清楚；非焦點部分則應自然暈開、淡入背景。背景常有大量留白、淡淡色霧或流動色塊，不需要完整填滿整張畫面。

筆觸應輕、透明、含水，不應厚塗。可以使用濕畫法形成柔霧暈染，也可以用乾筆在紙紋上留下破碎筆痕。水彩很適合呈現光線與空氣，畫面應有清透、柔和、未完成感，而不是過度精修、過度銳利或塑膠般平滑。整體應像顏料被水帶著走，具有偶然性、呼吸感與手作溫度。

### 色彩語彙

主要使用淡藍、灰藍、淡粉、淺紫、嫩綠、米白、茶色、淺赭、柔黃。色彩應透明、低到中飽和，透過水分稀釋呈現輕盈感。

陰影不應使用死黑，可以用藍灰、紫灰、茶褐或互補淡色逐層疊出。高光多由紙白保留，不要使用厚重白色顏料覆蓋。整體色彩要清新、柔和、通透。

### 可直接用 prompt

透明水彩畫風格，細緻水彩紙肌理，顏料以水分自然暈染與滲化，色彩透明輕盈，邊緣有柔和水痕與自然擴散效果，局部焦點清楚而背景淡化留白，淡藍、灰藍、淡粉、淺紫、嫩綠、米白、茶色與淺赭色調，整體清透、柔和、詩意、帶有手繪溫度，不使用厚重覆蓋與光滑數位漸層，而以透明色層、水痕、紙張纖維與留白建立畫面。

### 負面 prompt

避免厚重油畫、3D 渲染、CGI、塑膠質感、光滑數位插畫、霓虹色、強烈黑色陰影、過度銳利邊緣、無紙張肌理、無水痕、無透明感、過度精修、照片寫實、動漫風、企業向量圖、金屬反光、厚塗筆觸。

## 2. 油畫｜厚重筆觸古典油彩風格

### 風格核心

油畫的風格核心是厚度、層次、光影、筆觸、顏料質感與可塑形的體積感。它可以古典、寫實、巴洛克、印象派或現代表現，但共同特徵是顏料具有重量，可以透過罩染、厚塗、刮痕與筆觸建立深度。

用於圖片生成時，重點不是單純讓畫面像照片，而是要呈現「油彩表面、筆觸方向、顏料厚度與光影塑形」。主體應有油畫般的溫潤厚度，暗部可以深沉，亮部可以有厚塗高光，畫面應像真實顏料堆疊在畫布上。

### 視覺特徵

畫面應有可見畫布紋理與油彩層次。暗部可以深沉透明，像多層顏料慢慢罩染而成；亮部可以有 impasto 厚塗，讓高光帶有凸起的顏料感。筆觸方向應服務於形體，例如臉部筆觸沿著肌肉轉折，布料筆觸跟隨衣褶，天空與背景筆觸可更鬆動。

油畫可以有強烈光影，也可以柔和，但都應具備顏料厚度與可塑形體積。人物、靜物、風景、建築或抽象主體都可以透過油彩建立重量。不要讓畫面像光滑數位噴槍，應能看到筆毛拖曳、顏料堆積、顏色混合與局部刮痕。

構圖可以穩定、戲劇或自由，但畫面表面必須有「畫過」的感覺。邊緣可以有清楚與模糊的變化，焦點更精細，背景可鬆動。色彩混合應有自然油彩感，不是機械漸層。整體應厚實、溫潤、深度充足、富有繪畫存在感。

### 色彩語彙

常用赭石、焦茶、深紅、群青、橄欖綠、暖白、灰藍、土黃、黑褐。色彩可濃郁、厚重、低飽和或高對比，依主題調整。

亮部可使用暖白、金黃、淡膚色；暗部可使用焦茶、深藍、黑褐。整體色彩應具有油彩混合後的濃度與厚度，不要像扁平印刷色。

### 可直接用 prompt

傳統油畫風格，明顯畫布紋理與油彩顏料厚度，筆觸可見，暗部深沉透明，亮部具有 impasto 厚塗高光，主體以油畫光影塑造體積與重量，色彩層層堆疊，邊緣有清楚與柔化的變化，赭石、焦茶、深紅、群青、橄欖綠、暖白與灰藍色調，整體厚實、溫潤、古典、富有手工繪畫質感，不使用光滑數位噴槍，而以油彩筆觸、顏料堆積與畫布紋理建立畫面。

### 負面 prompt

避免光滑 CGI、3D 渲染、塑膠質感、無筆觸、無畫布紋理、平滑數位插畫、向量圖、動漫風、過度銳利攝影、霓虹科幻、低紋理、平面海報感、過度乾淨、廉價濾鏡、沒有顏料厚度。

## 3. 壓克力｜鮮明平塗現代顏料風格

### 風格核心

壓克力的風格核心是鮮明、乾淨、覆蓋力強、現代感與快速成形的顏料表面。它比水彩更不透明，比油畫更乾爽、明快，可以呈現平塗色塊、硬邊圖形、抽象構成、裝飾性圖案，也可以保留刷痕與刮刀痕。

用於圖片生成時，重點是「不透明顏料、鮮明色塊、清楚邊界與現代繪畫表面」。畫面可以明亮、活潑、圖案化，也可以粗獷、厚刷、具有手作顏料痕跡。

### 視覺特徵

畫面應有壓克力顏料的覆蓋感。色塊可以乾淨、飽和、邊界明確，不像水彩透明滲化，也不像油畫那樣深層罩染。顏料乾後表面可略帶霧面或半亮感，有刷痕、滾筒痕、刮刀痕、局部厚塗與層層覆蓋的痕跡。

構圖可以偏現代，適合大面積平塗、幾何區塊、抽象形狀、插畫式人物、裝飾背景、明確輪廓與高對比色彩。若是具象主題，形體應被簡化成明確色面，而不是照片般細膩。焦點可用清楚外輪廓與厚重顏料邊線強化。

壓克力可乾淨也可粗獷，但不應過度透明或柔焦。畫面應有直接、明快、人工控制感。層次可以透過色塊疊壓、局部露底、乾刷肌理與不透明覆蓋來建立。整體效果應現代、清楚、鮮明、有顏料質感。

### 色彩語彙

可使用亮紅、鈷藍、翠綠、亮黃、橘色、紫色、黑色、白色，也可加入土色、灰色形成現代平衡。色彩通常比水彩更飽和，比油畫更乾淨直接。

適合使用高對比色塊、互補色、平面背景與明確輪廓。避免過度灰濁與低彩度，除非刻意做極簡或工業風。

### 可直接用 prompt

壓克力顏料繪畫風格，不透明高覆蓋力色塊，鮮明乾淨的平塗表面，邊界清楚，帶有刷痕、刮刀痕與層層覆蓋的顏料肌理，構圖現代、直接、明快，可使用幾何區塊、簡化形體與高對比色彩，亮紅、鈷藍、翠綠、亮黃、橘色、紫色、黑色與白色色調，整體鮮明、現代、乾爽、有手工顏料表面，不使用透明水彩暈染與油畫深層罩染，而以不透明色塊與壓克力肌理建立畫面。

### 負面 prompt

避免照片寫實、光滑 CGI、3D 渲染、透明水彩感、過度柔焦、無刷痕、無顏料覆蓋感、低飽和灰暗、塑膠感數位插畫、細膩油畫罩染、霓虹科幻、過度複雜細節、無色塊結構。

## 4. 素描｜線條觀察草圖風格

### 風格核心

素描的風格核心是觀察、線條、結構、明暗、形體分析與草圖感。它不依賴華麗色彩，而是透過線、面、排線、擦痕、留白與紙張肌理建立畫面。素描可以是快速草圖，也可以是完整明暗研究。

用於圖片生成時，重點是「手繪線條與形體推敲」。畫面應像藝術家用鉛筆、炭筆或石墨在紙上觀察主體，不是照片轉黑白，也不是乾淨向量線稿。

### 視覺特徵

畫面應有大量手繪線條，包括輪廓線、結構線、輔助線、排線、交叉排線、擦拭痕與局部修正痕。線條可以輕重不同，有的準確清楚，有的探索性較強。焦點處線條更密、更精確，非焦點可用輕淡草線帶過。

形體應透過明暗與線條建立。陰影可以由斜向排線、交叉線、擦筆灰面或紙面留白形成，不應只是平滑灰階。比例、骨架、透視、體積與轉折要被看見，讓畫面有學院訓練或速寫觀察感。

紙張很重要，應保留米白、灰白或粗紙肌理。構圖可有未完成邊緣、局部空白、草稿痕跡、被擦掉的線或重畫的輪廓。整體應真實、安靜、觀察性強，有手和紙摩擦的質感，而不是數位黑白濾鏡。

### 色彩語彙

主要使用石墨灰、鉛筆灰、深灰、淡灰、紙白、米白、炭黑。可有少量暖褐或紙張泛黃感。

色彩應克制，重點是線條與明暗，而非彩色效果。不要使用高飽和色彩，除非是局部標記或混合媒材。

### 可直接用 prompt

傳統素描風格，手繪線條與觀察草圖感明顯，包含輪廓線、結構線、排線、交叉排線、擦痕與局部修正痕，形體透過明暗線條建立體積，紙張肌理清晰，石墨灰、深灰、淡灰、紙白與米白色調，畫面安靜、專注、具有藝術家手稿與寫生研究感，不使用照片黑白濾鏡或光滑數位線條，而以真實手繪線痕、紙面留白與明暗推敲建立畫面。

### 負面 prompt

避免照片黑白濾鏡、3D 渲染、CGI、油畫厚塗、彩色插畫、向量圖、動漫線稿、過度乾淨、無紙張肌理、無排線、無手繪修正痕、霓虹色、光滑數位陰影、塑膠質感。

## 5. 鉛筆｜細膩石墨明暗風格

### 風格核心

鉛筆的風格核心是細膩、灰階、線條控制、石墨光澤與層層明暗。相較於廣義素描，鉛筆更強調鉛芯在紙面上的細密筆觸、壓力變化、柔和灰階與精緻細節。

用於圖片生成時，重點是「石墨筆觸、紙紋、細膩灰階與手工推亮暗」。畫面可以寫實，也可以草圖化，但必須保留鉛筆線條與石墨質感。

### 視覺特徵

畫面應有細密鉛筆線條，能看到鉛芯隨手部壓力產生的深淺變化。陰影應由多層輕細排線、交叉排線或柔擦形成，不應是單純數位灰階。深色區域可有石墨壓深後略帶光澤的質感，亮部則由紙白保留或輕擦提亮。

輪廓可以清楚但不僵硬。人物皮膚、頭髮、布料、物件表面、植物或建築細節都應透過細小筆觸呈現。頭髮可以用一束束線條，金屬或玻璃可以用灰階反差，皮膚要靠細膩過渡而不是噴槍平滑。

紙張肌理應存在，尤其在大面積灰階中能看到鉛筆顆粒與紙紋。畫面可帶有未完成邊緣、淡淡草稿線或橡皮擦痕。整體應乾淨、細膩、安靜、有手工耐心，不要像照片轉灰階。

### 色彩語彙

主要使用淺灰、中灰、深灰、石墨黑、紙白、米白。可有輕微暖灰或冷灰差異，但不應出現鮮豔彩色。

石墨黑不應死黑，應有鉛筆層次與反光。亮部應保留紙面呼吸感。

### 可直接用 prompt

細膩鉛筆畫風格，石墨筆觸清晰可見，細密排線與交叉排線建立柔和灰階，紙張紋理明顯，深色區域具有鉛筆石墨光澤，亮部保留紙白，輪廓精準但帶手繪感，淺灰、中灰、深灰、石墨黑、紙白與米白色調，整體安靜、精緻、細膩、具有手工素描質感，不使用照片灰階濾鏡或光滑數位陰影，而以鉛筆壓力、線條密度與橡皮擦痕建立畫面。

### 負面 prompt

避免彩色插畫、油畫筆觸、水彩暈染、3D 渲染、CGI、照片轉黑白、過度平滑灰階、無紙紋、無鉛筆線條、向量線稿、動漫風、塑膠質感、霓虹色、厚重炭筆黑塊。

## 6. 彩色鉛筆｜細密疊色手繪風格

### 風格核心

彩色鉛筆的風格核心是細密線痕、層層疊色、紙紋顆粒、柔和但可控的色彩。它不像水彩會自然暈染，也不像油畫厚重覆蓋，而是透過一筆一筆的線條與顏色疊加建立色彩深度。

用於圖片生成時，重點是「彩色鉛筆的筆觸方向、顆粒感、疊色與紙張紋理」。畫面可以精緻、童趣、寫實、插畫化，但不能失去手繪線痕。

### 視覺特徵

畫面應看到細小的彩色筆觸與紙紋空隙。色彩不是平滑填色，而是由多層透明或半透明的鉛筆線條疊成。局部可以看到紅、藍、黃、綠等不同顏色交疊形成混色，而不是數位色盤直接填滿。

邊緣可以細膩清楚，適合描繪人物、動物、花卉、食物、日常物件、童書插畫或自然元素。陰影可以由深色鉛筆逐層加重，高光可保留紙白或使用淺色鉛筆。筆觸方向要貼合形體，例如毛髮沿生長方向，花瓣沿紋理方向，衣褶沿摺線方向。

整體質感應溫柔、手作、細緻。不要做成光滑數位插畫，也不要像蠟筆厚塊。彩色鉛筆應有耐心堆疊的感覺，畫面可保留少量紙白顆粒，形成自然手繪呼吸感。

### 色彩語彙

常用柔粉、淡藍、嫩綠、奶黃、橘紅、棕色、紫色、灰藍、米白。可高彩度也可低彩度，但要有鉛筆疊色感。

陰影可用互補色疊加，例如藍紫加深黃橙，棕紅加深膚色。避免單一死黑陰影與螢光數位色。

### 可直接用 prompt

彩色鉛筆手繪風格，細密彩色鉛筆線條與紙張顆粒清晰可見，色彩由多層疊色形成，筆觸方向貼合形體，邊緣精緻但保留手繪感，局部可見紙白空隙與不同顏色交疊，柔粉、淡藍、嫩綠、奶黃、橘紅、棕色、紫色與灰藍色調，整體溫柔、細膩、手作、具有插畫感，不使用光滑數位填色，而以彩鉛線痕、疊色與紙紋建立畫面。

### 負面 prompt

避免光滑數位插畫、向量圖、3D 渲染、CGI、油畫厚塗、水彩大面積暈染、無紙張肌理、無鉛筆線條、塑膠質感、過度銳利攝影、霓虹色、動漫賽璐璐、平面無顆粒填色。

色彩應平塗、乾淨、飽和，不宜使用大量漸層。紙張本身可帶纖維與霧面質感。

### 可直接用 prompt

傳統剪紙藝術風格，平面紙張剪裁與鏤空圖案，清楚的剪影輪廓，對稱構圖，正負形關係明顯，紙張邊緣帶有細小纖維與手工剪刀痕，可包含花鳥、動物、人物、雲紋、節慶與吉祥裝飾，朱紅、紙白、黑色、金色與青綠色調，整體民俗、平面、裝飾性強，不使用照片寫實與油畫明暗，而以紙片層次、鏤空花紋與剪裁邊緣建立畫面。

### 負面 prompt

避免照片寫實、3D 渲染、CGI、油畫厚塗、水彩暈染、複雜攝影光影、無鏤空、無紙張邊緣、無正負形、塑膠質感、霓虹色、動漫風、向量過度光滑、過度立體、低民俗感。

## 14. 彩繪玻璃｜宗教窗花透光風格

### 風格核心

彩繪玻璃的風格核心是玻璃分格、鉛條輪廓、透光色彩、宗教窗花感與拼接式圖像。它不是普通彩色插畫，而是像光線穿過有色玻璃，使畫面呈現寶石般的透明光感。

用於圖片生成時，重點是「鉛框分割、玻璃質地、透光、色塊拼接與窗面結構」。任何主題都應被轉化成由玻璃片拼成的圖像。

### 視覺特徵

畫面應有清楚的黑色或深色鉛條線，把主體與背景分割成許多玻璃片。每一塊玻璃都可以有不同透明度、顏色深淺、氣泡、裂紋、流動紋理或手工玻璃不均感。色彩像被光從背後照亮，具有內發光效果。

構圖可像教堂窗、圓形玫瑰窗、拱形窗、幾何窗格、聖像構圖或裝飾圖案。人物、動物、花卉、風景與抽象圖形都要被簡化成玻璃色塊。陰影不是油畫式明暗，而是由不同玻璃色與透光強度形成。

可以有光束、窗框、牆面投影或彩色光斑灑在地面上，但主體仍應是彩繪玻璃圖像。整體要華麗、神聖、透明、寶石般閃耀，具有手工玻璃與鉛框拼接感。

### 色彩語彙

常用寶石藍、深紅、金黃、翠綠、紫色、青藍、橙色、白色、黑色鉛框。色彩應飽和、透亮、像光穿過玻璃。

避免灰暗無光與塑膠霓虹。高光應像玻璃反射與透光，不是金屬反光。

### 可直接用 prompt

彩繪玻璃藝術風格，畫面由深色鉛條分割成多片透明有色玻璃，玻璃片具有氣泡、裂紋、流動紋理與手工不均質感，光線從背後穿透形成寶石般內發光效果，構圖可像教堂拱形窗、玫瑰窗或裝飾窗花，寶石藍、深紅、金黃、翠綠、紫色、青藍、橙色與白色色調，整體華麗、神聖、透明、具有窗花拼接感，不使用油畫厚塗與照片寫實，而以鉛框、玻璃色塊與透光效果建立畫面。

### 負面 prompt

避免照片寫實、油畫筆觸、水彩暈染、3D 塑膠材質、無鉛條分割、無玻璃透光、無窗格結構、低飽和灰暗、向量平面無質感、動漫風、普通彩色插畫、金屬過度反光、沒有玻璃氣泡與裂紋。

## 15. 馬賽克｜碎片拼貼鑲嵌風格

### 風格核心

馬賽克的風格核心是碎片拼貼、鑲嵌、硬質顆粒、格狀結構與由小塊材料組成完整圖像。它可以像古羅馬壁面、拜占庭金色聖像、現代瓷磚牆或石片拼圖。

用於圖片生成時，重點是「小片材料組合成畫面」。主體不能只是加上格子濾鏡，而應真的由石片、玻璃片、陶片或瓷磚一片片拼成。

### 視覺特徵

畫面應由大量小型碎片構成，每片形狀可略有不同，例如方形、梯形、不規則石片、玻璃片或陶瓷片。碎片之間應有明顯縫隙、灰泥線或鑲嵌邊界。遠看形成完整圖像，近看能看到材料顆粒。

碎片的排列應順著形體走向。例如人物臉部的碎片跟隨臉部曲面，衣褶碎片形成流線，背景碎片可呈放射狀、波紋狀或幾何排列。不要只做均勻像素化，馬賽克需要手工拼貼秩序與材料差異。

材質可有石頭粗糙、玻璃反光、陶片霧面、金箔小片或古老牆面裂痕。色彩可以豐富但由小片構成。整體應有堅硬、古老、裝飾、拼接、壁面藝術感。

### 色彩語彙

常用金色、寶石藍、赭紅、土黃、象牙白、墨黑、翠綠、灰色、陶土色。拜占庭方向可更金碧輝煌；古羅馬方向可偏土色與石材感。

色彩應以小塊材料呈現，不應是平滑漸層。

### 可直接用 prompt

馬賽克鑲嵌藝術風格，整個畫面由大量小型石片、玻璃片、陶片與瓷磚碎片拼接而成，每片形狀略有差異，碎片之間有清楚灰泥縫隙，遠看形成完整圖像，近看可見硬質顆粒與材料質感，碎片排列跟隨人物、物體與背景形體走向，金色、寶石藍、赭紅、土黃、象牙白、翠綠與陶土色調，整體古典、裝飾、堅硬、具有壁面鑲嵌手工感，不使用平滑數位像素濾鏡，而以真實碎片、縫隙與拼貼秩序建立畫面。

### 負面 prompt

避免照片寫實、油畫筆觸、水彩暈染、3D 塑膠、無碎片、無灰泥縫隙、普通像素化濾鏡、過度平滑、向量圖、動漫風、低細節、無材料差異、霓虹色、沒有鑲嵌感、沒有硬質表面。

## 16. 刺繡｜線繡纖維布面風格

### 風格核心

刺繡的風格核心是線、針腳、布面、纖維、手工縫製與圖案化表面。它不是畫筆顏料，而是用一針一線把圖像繡在布上，透過線材方向、針腳密度、纖維光澤與布料紋理建立畫面。

用於圖片生成時，重點是「繡線真的縫在布上」。主體應由針腳與線段構成，而不是普通插畫加上布紋濾鏡。

### 視覺特徵

畫面應能看到布料底材，例如棉布、麻布、帆布或絲布，表面有經緯紋、纖維毛邊與微微起伏。圖像由繡線構成，線段有方向、有厚度、有微光，每一區域都能看到針腳排列。不同部分可使用平針、緞面繡、鎖鏈繡、長短針、十字繡、法國結等效果。

針腳方向應貼合形體。花瓣可用放射狀針腳，毛髮可用長短線，衣褶可順著布料流向，背景可用規律填繡或保留布面。邊緣不應像數位矢量一樣完美，而應有線頭、毛絮、輕微錯位與手作不規則感。

刺繡可精緻也可民俗。構圖可以是胸章、布面圖案、手帕、壁掛、服裝刺繡、花鳥、人物、文字或裝飾符號。整體應有柔軟、纖維、可觸摸的質感，像線材凸起在布面上。

### 色彩語彙

常用棉線白、米色布底、紅線、藍線、綠線、金線、粉色、土黃、黑線、深棕。色彩可鮮明，也可溫柔復古。

線材可有微微絲光，但不應變成塑膠亮面。布底色會影響整體氣氛，可用麻布米色、深藍布、黑布或白布。

### 可直接用 prompt

刺繡手工藝風格，圖像由一針一線的繡線構成，布面經緯紋與纖維肌理清晰可見，針腳排列有方向與厚度，可見平針、緞面繡、長短針、鎖鏈繡與十字繡效果，線材微微凸起並帶有纖維光澤，邊緣有手工線頭與輕微不規則感，米色布底、紅線、藍線、綠線、金線、粉色、黑線與深棕色調，整體溫暖、柔軟、手作、具有可觸摸的布面刺繡質感，不使用普通數位插畫或印刷圖案，而以針腳、繡線與布料纖維建立畫面。

### 負面 prompt

避免照片寫實、油畫筆觸、水彩暈染、3D 塑膠、無布料紋理、無針腳、無線材厚度、普通平面印刷、向量圖、動漫風、過度光滑、霓虹色、低細節、沒有纖維毛邊、沒有手工不規則感。
