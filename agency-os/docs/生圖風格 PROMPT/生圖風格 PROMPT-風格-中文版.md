# 圖片生成風格 Prompt｜通用風格分類中文版

> 依照截圖中的風格標籤整理，共 32 種，未遺漏。  
> 每一項皆包含：風格核心、視覺特徵、色彩語彙、可直接用 prompt、負面 prompt。

## 1. 動漫 anime｜日式動漫風格

### 風格核心

動漫風格的核心是高度設計化的人物造型、清楚輪廓線、誇張但可讀性強的表情，以及介於平面插畫與動畫分鏡之間的視覺語言。它不追求完全照片寫實，而是把人物、場景、動作與情緒轉化為更鮮明、更符號化、更具戲劇張力的圖像。

用於圖片生成時，重點是「角色辨識度」與「情緒表現」。人物五官、髮型、眼神、姿態、服裝輪廓都要清楚，畫面應該像動畫作品中的關鍵視覺、角色插畫或劇情瞬間。

### 視覺特徵

人物通常具有較大的眼睛、清楚的瞳孔高光、精緻髮束、乾淨輪廓線與簡化但有吸引力的臉部結構。表情可以比寫實人物更明確，例如堅定、害羞、憤怒、驚訝、冷淡、溫柔或熱血，但不要讓表情失控或五官崩壞。

線條是重要骨架。外輪廓應乾淨流暢，髮絲、衣褶、手勢與配件可以用較細線條補充。陰影多使用 cel shading 或柔和動畫陰影，暗部形狀清楚，不需要完全真實的光線物理。背景可以是城市、校園、幻想場景、室內或自然風景，但要服務角色情緒，不要搶走主體。

構圖可有強烈角色中心、動態姿勢、斜角視角、特寫、半身像、全身立繪或動畫海報式安排。畫面應乾淨、清楚、富有敘事感，避免混成普通 3D 遊戲渲染或歐美卡通。

### 色彩語彙

常用乾淨高飽和色、柔和膚色、明亮髮色、校服色、天空藍、櫻花粉、深藍陰影、暖黃光、紫色夜景與高光白。色彩可以鮮明，但要有動畫分層感。

陰影通常偏藍紫、灰藍或暖棕，不應過度髒灰。整體色彩可根據主題偏熱血、清新、科幻、校園、奇幻或暗黑，但仍需保留動漫式乾淨線條與角色可讀性。

### 可直接用 prompt

日式動漫風格，清楚流暢的角色輪廓線，大眼睛與明亮瞳孔高光，精緻髮束與明確五官，表情具有強烈情緒可讀性，人物姿態自然但富有戲劇張力，乾淨線稿，cel shading 動畫陰影，明確高光與簡潔暗部，畫面像動畫關鍵視覺或角色插畫，色彩乾淨鮮明，背景服務角色情緒，整體具有日式動畫人物設計、青春感、敘事感與視覺吸引力。

### 負面 prompt

避免照片寫實、3D 渲染、CGI 塑膠皮膚、歐美卡通臉、過度寫實毛孔、低品質手部、五官崩壞、眼睛不對稱、粗糙線稿、髒灰色彩、過度油畫筆觸、真實攝影景深、恐怖變形、角色不可讀。

## 2. 動畫 animation｜動畫電影風格

### 風格核心

動畫風格的核心是清楚、流暢、適合動起來的造型設計。它不限定日式動漫，可以包含手繪動畫、數位動畫、動畫電影背景、美術設定與角色動畫語言。重點是形狀簡潔、情緒明確、動作有生命感、畫面適合敘事。

用於圖片生成時，應讓主體像動畫電影中的一幀：角色、場景、光線和構圖都具有劇情功能。畫面不一定要極度寫實，但必須乾淨、可讀、溫暖且具有動態潛力。

### 視覺特徵

角色形體通常經過設計與簡化，輪廓清楚，姿勢可讀性高。人物或生物可以有誇張比例，但應合理、穩定、富有表演性。手勢、眼神、身體方向與重心要明確，讓觀者能感受到角色正在思考、行動或即將移動。

背景常具有動畫場景設計感：簡化透視、清楚前中後景、柔和光線、可讀的色塊與乾淨空間。材質可比照片更理想化，例如木頭、石頭、布料、雲朵、水面都可用簡化筆觸和大色塊處理。

構圖應像分鏡或電影場面，注重視線引導。光影可以戲劇化，但不應像真實攝影那樣混亂。整體要有敘事、節奏、動作和情緒，而不是靜態商品圖。

### 色彩語彙

常用清亮暖色、柔和環境光、天空藍、草綠、暖橙、奶油白、柔粉、深紫陰影與金色高光。色彩比現實更乾淨、更理想化，通常有明確主色調。

可依情境調整成溫馨、冒險、奇幻、幽默或感傷，但色彩組織要清楚，避免過度髒亂與無目的的高飽和。

### 可直接用 prompt

動畫電影風格，清楚可讀的角色設計，流暢輪廓線，簡化但有生命力的形體，人物姿態具有表演性與動作感，背景像動畫場景美術，前中後景層次清楚，色塊乾淨，光線柔和而有敘事功能，整體像動畫電影中的一幀，溫暖、清晰、情緒明確、適合故事畫面，具有手繪動畫與數位動畫結合的質感。

### 負面 prompt

避免照片寫實、過度複雜紋理、3D 塑膠感、僵硬姿勢、表情空洞、畫面雜亂、低可讀性、過度黑暗、無故事感、真實攝影噪點、厚重油畫、角色比例崩壞、背景搶走主體。

## 3. 漫畫 comic｜漫畫分鏡與印刷風格

### 風格核心

漫畫風格的核心是圖像敘事、線條表現、分格節奏與印刷語言。它不只是畫成角色插畫，而是讓畫面具有漫畫頁、封面、單格故事或圖像小說的敘事感。重點是清楚線稿、強烈輪廓、動態構圖、情緒符號與圖文分鏡感。

用於圖片生成時，任何主題都可以被轉化成漫畫畫面：主體要有清楚動作，場面要有戲劇張力，光影和線條要服務故事，而不是追求照片真實。

### 視覺特徵

線條是最重要的表現工具。輪廓線可粗細變化，暗部可用排線、交叉線、黑色塊面或網點處理。動作場景可加入速度線、衝擊線、音效字、誇張構圖或強烈透視。靜態場景則可用分鏡式裁切、黑框、對白框或封面構圖呈現。

人物表情與姿態可比寫實更誇張，眉眼、嘴型、手勢和肢體方向要清楚。場景細節可以依漫畫類型調整：美式漫畫可更重黑線與肌肉結構，日式漫畫可更細線與網點，歐洲漫畫可更注重場景和色塊。

畫面應有印刷感，例如半色調網點、紙張纖維、墨線邊緣、平面色塊。不要讓它變成光滑 3D 或一般插畫。

### 色彩語彙

可使用黑白高對比、四色印刷感、半色調紅藍黃、強烈陰影黑、鮮紅、深藍、亮黃、墨黑、紙白。彩色漫畫可使用平面色塊與清楚陰影。

黑白漫畫則重視墨線、留白、網點和黑色塊面。整體色彩應有印刷限制與圖像張力。

### 可直接用 prompt

漫畫風格，清楚有力的墨線輪廓，粗細變化線稿，強烈分鏡式構圖，畫面具有故事瞬間與動態張力，可加入排線、交叉線、半色調網點、速度線、衝擊線與印刷紙張質感，人物表情和姿態清楚誇張，色彩以平面色塊與高對比陰影建立畫面，整體像漫畫封面、單格分鏡或圖像小說插頁，具有強烈敘事性與印刷感。

### 負面 prompt

避免照片寫實、3D 渲染、光滑 CGI、無線稿、無網點、沒有故事感、柔焦油畫、低對比、過度真實皮膚、商業攝影、畫面沒有分鏡感、線條混亂、字體亂入、角色表情不可讀。

## 4. 卡通 cartoon｜誇張卡通風格

### 風格核心

卡通風格的核心是簡化、誇張、幽默、形狀設計與高度可讀性。它比動漫更符號化，比寫實更自由，通常使用圓潤外形、誇張比例、明確表情和輕鬆節奏。畫面重點不是逼真，而是讓角色或主體一眼就能被理解。

用於圖片生成時，任何主體都可以被轉化為親切、幽默、誇張且有彈性的卡通形象。形體應該更大膽，情緒更直接，動作更有彈性。

### 視覺特徵

人物、動物或物件可有大眼睛、大頭、小身體、圓形手腳、簡化五官與誇張表情。線條通常粗而乾淨，輪廓明確。形體可以拉伸、壓縮、彎曲，帶有動畫中的 squash and stretch 彈性。

背景應簡潔清楚，不需要複雜寫實紋理。物件可以被幾何化、圓潤化或符號化。表情是重點：開心、驚訝、調皮、困惑、害怕都應清楚明確。陰影通常簡單，色塊平整。

構圖適合海報、貼圖、兒童節目、動畫短片或幽默插畫。不要讓畫面過度陰暗、寫實或成人化。

### 色彩語彙

常用明亮原色、柔和糖果色、亮黃、天藍、草綠、橘色、粉紅、純白、黑色輪廓。色彩直接、清楚、輕快，不需要複雜灰階。

陰影可用同色系深一階處理，保持乾淨平面。整體應活潑、清楚、友善。

### 可直接用 prompt

卡通風格，簡化而誇張的造型，大頭小身體或圓潤比例，清楚粗輪廓線，表情直接可讀，動作富有彈性與幽默感，平面色塊，簡單陰影，背景乾淨不複雜，色彩明亮輕快，整體像動畫短片、幽默插畫或角色貼圖，親切、可愛、活潑、具有高度視覺可讀性。

### 負面 prompt

避免照片寫實、恐怖寫實、3D 塑膠玩具感、過度複雜紋理、厚重油畫、暗黑暴力、表情模糊、細節過多、真實攝影光影、低飽和灰暗、比例僵硬、沒有幽默感。

## 5. 吉卜力 Ghibli｜手繪日式動畫電影美術風格

### 風格核心

吉卜力系風格的核心是溫暖手繪動畫感、自然與生活並存的詩意、柔和光線、細膩背景，以及具有呼吸感的角色與場景。它不只是可愛動畫，而是一種把日常、自然、成長、冒險與淡淡懷舊融合在一起的動畫電影美術語言。

用於圖片生成時，重點是「手繪背景」與「溫柔世界觀」。畫面應像一幀充滿空氣、風、草木、水氣與生活細節的動畫電影畫面，而不是光滑 3D 或普通動漫肖像。

### 視覺特徵

背景非常重要。森林、草地、雲朵、鄉村小屋、老街、海邊、車站、飛行器、廚房、溫室或神祕自然空間都可以有細膩手繪感。植物應有豐富但不機械的筆觸，雲和天空柔軟，建築帶有生活痕跡。

角色設計通常樸實、自然、表情真誠，不需要過度性感或華麗服裝。人物比例可接近動畫化寫實，五官簡潔，情緒溫和但有生命力。畫面中常有風感，例如飄動的頭髮、衣角、草葉或雲層。

光線應柔和、自然，有清晨、午後、黃昏或陰天散射光。場景充滿細節，但不雜亂。整體應有童年記憶、自然神祕、日常溫度和冒險前的寧靜。

### 色彩語彙

常用草綠、天空藍、雲白、米黃、暖棕、淡橙、柔灰、森林綠、湖水藍、土色與柔和膚色。色彩清新但不螢光，像手繪背景顏料。

整體配色可偏自然、溫暖、懷舊。陰影柔和，不要冷硬黑色。光感應該像手繪動畫中的自然日光。

### 可直接用 prompt

手繪日式動畫電影美術風格，溫暖自然的動畫背景，細膩手繪草木、雲朵、天空、老建築與生活物件，角色造型樸實自然，表情真誠溫柔，畫面充滿風感、空氣感與童年記憶，柔和自然光，清晨或午後的溫暖色調，草綠、天空藍、米黃、暖棕、雲白與柔灰色彩，背景細節豐富但不雜亂，整體詩意、懷舊、冒險、自然、療癒，像手繪動畫電影中的一幀。

### 負面 prompt

避免光滑 3D 渲染、CGI 塑膠感、照片寫實、過度動漫偶像化、霓虹科幻、厚重油畫、恐怖陰暗、低細節背景、沒有自然感、沒有手繪質感、過度銳利數位邊緣、商業遊戲 UI 感。

## 6. 像素 pixel art｜像素藝術風格

### 風格核心

像素藝術的核心是以明顯像素格建立圖像，而不是模糊連續筆觸。畫面由小方格色塊組成，透過有限解析度、有限色盤與精準排列創造角色、場景、光影和質感。它具有復古遊戲、8-bit、16-bit、掌機遊戲或獨立遊戲美術的語言。

用於圖片生成時，重點是「像素格不可被消除」。畫面不能只是普通插畫加馬賽克濾鏡，而要從造型、邊緣、陰影到材質都以像素邏輯成立。

### 視覺特徵

輪廓應呈現階梯狀 pixelated edges，不要反鋸齒過度平滑。角色和物件需要被簡化成清楚剪影，細節用少量像素暗示。眼睛、按鈕、光點、反光、陰影都應由明確色塊組成。

可使用等角視角、橫向卷軸、俯視 RPG、平台遊戲、復古介面、遊戲場景或角色 sprite 構圖。背景可有瓦片式地面、重複圖案、方格雲、像素樹、像素城市或低解析度光效。

明暗應以有限階層處理，例如三到五個亮度層級。材質不可細膩噴槍化。整體要乾淨、銳利、格狀、復古而可讀。

### 色彩語彙

可使用限制色盤：8-bit 原色、16-bit 高飽和色、復古掌機綠、霓虹藍紫、暖橙、深靛藍、黑色輪廓、亮白高光。色彩數量應控制，不要過度漸層。

陰影用色塊分層，不用柔焦。可依主題選擇復古遊戲、可愛像素、暗黑像素或賽博像素色盤。

### 可直接用 prompt

像素藝術風格，明顯低解析度像素格，階梯狀輪廓邊緣，有限色盤，清楚剪影，角色與物件由方形像素色塊組成，陰影以分層像素色塊呈現，不使用平滑漸層，畫面像 8-bit 或 16-bit 復古遊戲場景、角色 sprite 或獨立遊戲美術，構圖清楚，可讀性高，像素格銳利可見，具有懷舊遊戲感與手工像素排列質感。

### 負面 prompt

避免照片寫實、平滑數位插畫、抗鋸齒過度、柔焦、3D 渲染、CGI、油畫筆觸、沒有像素格、過度高解析細節、模糊馬賽克濾鏡、無限制色盤、真實攝影光影、塑膠質感。

## 7. 寫實 photoreal｜照片寫實風格

### 風格核心

寫實風格的核心是讓畫面看起來像真實攝影或高階寫實渲染，重視光線、材質、比例、解剖、透視、鏡頭感、環境細節與自然瑕疵。它不應像插畫、動畫或符號化圖像，而要讓觀者相信畫面中物件真的存在於某個可被拍攝的空間。

用於圖片生成時，重點是「可信度」。主體需要有正確的材質反應、自然光影、真實尺寸感和環境互動。

### 視覺特徵

人物需要真實皮膚質感，包括毛孔、細紋、微小瑕疵、自然膚色變化和合理眼神高光。服裝應有真實織物皺褶與材質反射。金屬、玻璃、木頭、皮革、石材、水面等都應符合物理質感。

光線要有明確來源，可是自然窗光、陰天散射光、黃昏逆光、棚拍柔光或夜間人工光。陰影方向、反射、高光和接觸陰影必須合理。背景不應像貼圖，前後景景深、焦距、透視和空氣感要一致。

構圖可像 DSLR、電影劇照、手機攝影、棚拍肖像、紀實攝影或產品攝影。畫面應保留自然不完美，例如微小雜訊、鏡頭景深、真實邊緣，不要過度美化成塑膠感。

### 色彩語彙

色彩依照光源與環境變化，通常包括自然膚色、環境反射色、真實白平衡、陰影藍灰、暖光橙黃、城市夜景色、自然綠與天空藍。色彩不應過度平面或卡通化。

可使用電影色調或攝影調色，但仍要保留真實材質和合理動態範圍。

### 可直接用 prompt

## 8. 印象派 impressionist｜印象派光色風格

### 風格核心

印象派的核心是捕捉瞬間光線、空氣、色彩顫動與自然感受，而不是描繪精確輪廓。畫面重點不是物件本身，而是光如何在某一刻落在物件上，讓形體被色彩、筆觸和大氣感柔化。

用於圖片生成時，任何主題都應被轉化為戶外光線中的色彩印象。輪廓可以鬆散，細節不必精雕，但整體光感必須明亮、流動、自然。

### 視覺特徵

筆觸應短促、碎裂、可見，像用小筆快速捕捉光色。樹葉、水面、人物、建築、天空、花草和道路都可以由並置色塊組成。邊緣不要太銳利，物體可像在空氣中微微震動。

陰影不能使用死黑，應以藍紫、灰綠、淡粉、冷暖互補色構成。水面反射、霧氣、晨光、午後光、花園、河岸和城市戶外場景都很適合。構圖可以平靜，但畫面表面必須活躍。

整體要有戶外寫生感，不要像攝影棚照明。筆觸鬆動而有節奏，色彩清亮，畫面像一瞬間的視覺感受。

### 色彩語彙

常用淡藍、薰衣草紫、粉紅、草綠、檸檬黃、奶油白、淺灰、湖水藍、暖橙和柔和陰影色。色彩通常明亮、通透、不髒黑。

整體可偏春日、午後、花園、水面或霧氣氛圍。重點是光色，而非重輪廓。

### 可直接用 prompt

### 負面 prompt

## 9. 後印象派 post-impressionist｜後印象派主觀色彩風格

### 風格核心

後印象派的核心是在印象派光色基礎上加入更強烈的結構、主觀色彩、情緒筆觸與象徵性。它不只是捕捉眼前光線，而是讓自然、人物和空間帶有畫家內在感受。畫面可以更厚重、更有方向性、更平面化或更結構化。

用於圖片生成時，重點是讓主題不再只是客觀景物，而成為色彩、筆觸、結構和情緒的重組。

### 視覺特徵

筆觸通常比印象派更明顯、更有方向感。天空、樹木、道路、人物、建築、花朵可以被短筆、旋轉筆觸、色塊或深色輪廓重構。形體可以有主觀變形，不必完全符合現實。

色彩可以不自然但有情緒邏輯，例如藍色天空與黃色土地強烈對比，綠色臉部陰影，橙色樹幹，紫色山坡。構圖可能平面化，也可能有厚重結構。輪廓可明確，色塊可飽和。

整體應比印象派更強烈、更個人、更有精神張力。畫面可以接近梵谷式筆觸、高更式平面色塊或塞尚式結構，但要保持後印象派的主觀性。

### 色彩語彙

常用鈷藍、鉻黃、赭石、橙色、翠綠、深藍、紫色、土紅、黑色輪廓和奶油白。色彩可以高飽和、互補對比強。

陰影不必寫實，可用情緒色。整體色彩應具有主觀表現力。

### 可直接用 prompt

## 10. 表現主義 expressionist｜情緒扭曲表現風格

### 風格核心

表現主義的核心是把內在情緒、焦慮、痛苦、狂喜、恐懼或精神張力外化為色彩、線條與形體扭曲。它不追求客觀真實，而是讓畫面看起來像被情緒推動、壓迫或撕裂。

用於圖片生成時，重點是「情緒優先於真實」。人物、空間、背景和色彩都可以變形，用來表達心理狀態。

### 視覺特徵

線條可以粗獷、扭曲、尖銳、不安。人物臉部可拉長、變形，眼神可空洞、恐懼、狂熱或麻木。身體姿態可緊繃、彎曲、壓迫、孤立。背景不應只是環境，而應像心理壓力場，牆壁、天空、道路、城市或室內空間都可以彎曲或傾斜。

筆觸通常強烈、粗糙、有刮擦感。色彩塊可以不自然，紅色可表示焦慮或暴力，綠色可表示病態，紫色和黑色可增加壓迫。構圖可不穩定，使用斜線、封閉空間、強烈前景或孤立人物。

整體不需要漂亮，但要有力量。它應像一種心理尖叫，而不是乾淨插畫。

### 色彩語彙

常用血紅、橙紅、酸綠、深紫、墨黑、病態黃、灰藍、暗棕、冷白。色彩可高對比、不自然、帶壓迫感。

陰影可以厚重，背景色可扭曲情緒。避免太甜美或過度自然。

### 可直接用 prompt

## 11. 超現實 surreal｜超現實夢境風格

### 風格核心

超現實風格的核心是把不可能的事物以看似合理或精密的方式放在同一畫面中，製造夢境、潛意識、荒謬、象徵和現實錯位。畫面可以非常寫實，也可以詩意模糊，但必須讓觀者感覺它像夢裡的邏輯。

用於圖片生成時，重點不是隨機拼貼，而是「不合理但有內在邏輯」。物件之間可以違反現實，但要形成心理或象徵關係。

### 視覺特徵

常見特徵包括漂浮物體、巨大化小物、融化形體、變形身體、不可能建築、雙重影像、空曠地平線、鏡子、門、眼睛、雲、沙漠、海面、室內外錯置。物件邊緣可以精準，讓荒誕更可信。

構圖可以空曠、冷靜、對稱或戲劇化。光線可像夢中無來源的光，也可像烈日下的銳利陰影。背景可真實但事件不可能。主體可以與環境比例錯亂，形成孤立與神祕感。

不要只是普通奇幻。超現實需要潛意識、符號、沉默、荒謬和不安。

### 色彩語彙

可使用乾燥沙色、天空藍、雲白、冷灰、深海藍、象牙白、暗紅、金色、黑色陰影。也可以用柔和夢境色，如淡粉、淡紫、銀藍。

色彩不必全部鮮豔，重點是營造異常而可信的夢境空氣。

### 可直接用 prompt

### 負面 prompt

## 12. 立體派 cubist｜立體派多視角幾何風格

### 風格核心

立體派的核心是把主體拆解成幾何平面，再從多個角度同時重組。它不追求單一透視，也不追求自然寫實，而是讓正面、側面、俯視、局部剖面和背景平面同時存在於一個畫面中。

用於圖片生成時，重點是「分解與重組」。人物、物件、空間都應被切割成平面結構，使畫面具有分析性與現代主義張力。

### 視覺特徵

人物臉部可同時出現正面眼睛、側面鼻子、錯位嘴巴和不對稱輪廓。物體可被切成三角形、梯形、矩形、多邊形平面。背景和主體邊界可互相滲透，讓空間破碎但有秩序。

線條可銳利，平面邊界清楚。構圖應像拼貼、分析圖或碎裂玻璃，但不能只是亂碎片。每一個碎片都應有結構關係。透視可以被壓扁，多視角同時出現。

適合肖像、靜物、樂器、城市、室內、身體或機械物件。整體要有理性、實驗、幾何和結構感。

### 色彩語彙

分析立體派常用赭石、灰、棕、黑、米白、暗藍。綜合立體派可加入紅、黃、綠、藍與拼貼紙感。色彩通常平面、克制或局部強烈。

陰影不應真實，應以幾何面明暗建立結構。

### 可直接用 prompt

立體派風格，主體被分解成多個幾何平面，正面、側面、俯視與局部剖面同時存在，人物五官或物件結構錯位重組，背景與主體邊界互相滲透，空間破碎但有理性秩序，使用三角形、矩形、梯形和多邊形色面，構圖像分析圖、拼貼與現代主義繪畫結合，赭石、灰、棕、黑、米白與暗藍色調，整體智性、結構化、平面化、具有多視角張力。

### 負面 prompt

避免照片寫實、傳統單點透視、柔和油畫、3D 渲染、CGI、自然臉部比例、普通漫畫、無幾何分解、無多視角、隨機碎片、霓虹科幻、過度圓滑、沒有結構邏輯。

## 13. 新藝術 art nouveau｜新藝術曲線裝飾風格

新藝術風格的核心是流動曲線、植物藤蔓、優雅女性、裝飾邊框與自然形態的平面化美感。畫面像精緻海報、裝飾畫或工藝設計，重視線條韻律與整體裝飾秩序。

用於圖片生成時，重點是讓主體被曲線、花草、拱形框、長髮、藤蔓與柔和圖案包圍，形成優雅、浪漫、復古的裝飾性畫面。

### 視覺特徵

線條應細緻、流暢、有彈性。人物姿態優雅，頭髮、衣褶、花草和背景圖案可互相延伸成曲線。構圖常有中央人物、圓形光環、拱門、對稱邊框或海報式排版。

背景不追求真實空間，而是使用花卉、藤蔓、葉片、波浪線、幾何邊框和裝飾文字區塊。人物輪廓清楚，色彩平塗，陰影溫和。整體像十九世紀末到二十世紀初的藝術海報或裝飾插圖。

### 色彩語彙

## 14. 裝飾藝術 art deco｜裝飾藝術幾何奢華風格

裝飾藝術的核心是幾何秩序、對稱構圖、金屬質感、奢華材料、流線型現代感與二十世紀初都會繁華。它比新藝術更硬朗、更幾何、更建築化，常讓畫面具有高級飯店、劇院、摩天樓、爵士時代或豪華海報的氣質。

## 15. 普普 pop art｜普普藝術風格

### 風格核心

普普藝術的核心是大眾文化、商業印刷、商品化圖像、機械複製、高飽和色彩和冷幽默。畫面可像廣告、漫畫、絲網印刷、包裝設計或媒體圖像，把日常物件與人物轉化成鮮明、扁平、可複製的視覺符號。

## 32. 黑白 monochrome｜黑白單色風格

### 風格核心

黑白風格的核心是去除色彩後，以明暗、線條、質感、形體和構圖建立畫面。它可以偏攝影、素描、版畫、電影黑白、墨水畫或高對比海報，但重點是讓黑、白、灰本身成為視覺語言。

### 視覺特徵

整體應避免彩色殘留。黑白不是低飽和彩色，而是完整的單色視覺系統。

### 色彩語彙
