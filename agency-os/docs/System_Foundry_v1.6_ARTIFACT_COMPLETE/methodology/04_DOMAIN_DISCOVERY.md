# Domain Discovery Standard

## Purpose
定義 System Foundry 在此領域的最低可重用標準。

## Required Scope
- ubiquitous language
- entities
- aggregates
- bounded contexts
- ownership
- invariants
- state machines

## Mandatory Questions
- Why is this required?
- Current state?
- Target state?
- Evidence?
- Alternatives?
- Failure mode?
- Exact path?
- Migration?
- Test?
- Rollback?
- Expected result?

## Output Contract
```text
WHAT
WHY
WHERE
DEPENDENCIES
RISK
TEST
ROLLBACK
EXPECTED RESULT
```

## Evidence States
VERIFIED / INFERRED / ASSUMED / UNKNOWN / DISPUTED
