# Architecture Options Standard

## Purpose
定義 System Foundry 在此領域的最低可重用標準。

## Required Scope
- 3+ options
- trade-offs
- 5/10/30-year test
- migration
- rollback
- cost

## Mandatory Questions
- Why is this required?
- Current state?
- Target state?
- Evidence?
- Alternatives?
- Failure mode?
- Exact path?
- Migration?
- Test?
- Rollback?
- Expected result?

## Output Contract
```text
WHAT
WHY
WHERE
DEPENDENCIES
RISK
TEST
ROLLBACK
EXPECTED RESULT
```

## Evidence States
VERIFIED / INFERRED / ASSUMED / UNKNOWN / DISPUTED
