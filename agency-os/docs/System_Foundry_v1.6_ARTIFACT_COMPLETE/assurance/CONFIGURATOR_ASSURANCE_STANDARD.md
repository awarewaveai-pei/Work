# Configurator Assurance Standard

A release of the configurator is blocked unless tests prove: binary-only answers; active-question completeness; inactive-question tamper rejection; question/rule/capability reference integrity; capability closure; contradiction blocking; locked Foundation Baseline; deterministic plan output; custom requirement preservation; selected-module generation; unselected-module absence; schema-valid project profile; staging/atomic generation; and no overwrite of existing targets.
