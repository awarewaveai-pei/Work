# System Foundry v1.2 Universal — Changelog

v1.2 adds reusable project-lifecycle controls identified by comparing v1.1 against a mature reference project.

Added: authority/autonomy, R0-R4 risk, tool/network boundaries, controlled exceptions, execution state machine, canonical statuses, structured handoff, supply-chain security, release evidence, lifecycle/deprecation, external-fact freshness, provider resilience, audit events, golden contract tests, universal system archetypes, bootstrap intake and `.foundry/` project control plane.

The reference project's domain-specific cognitive-method schemas, tenant-specific design, and AI-LEGO nomenclature were deliberately NOT copied into the Foundry kernel.
