# Foundry Runtime

This directory converts the Foundry Constitution from guidance into enforceable orchestration.

## Runtime guarantees
- fail-closed stage gates
- non-overridable subagent inheritance
- independent design/review/assurance roles
- evidence-required factual findings
- root-cause gate before implementation
- migration/rollback gate before production-affecting change
- retained verification evidence before DONE

## Canonical flow
`INTAKE -> CURRENT_STATE -> RESEARCH -> DOMAIN -> OPTIONS -> ENGINEERING_REVIEW -> COMMERCIAL_REVIEW -> FALSIFICATION -> RED_TEAM -> COMPLEXITY -> CONVERGENCE -> ASSURANCE -> HUMAN_APPROVAL -> REPO_BOOTSTRAP -> IMPLEMENTATION -> VERIFICATION -> RELEASE -> POST_RELEASE_PROOF`
