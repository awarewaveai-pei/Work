# Questionnaire Design Standard

## Eligibility
A user question is allowed only when both YES and NO are legitimate product/business outcomes, the answer cannot be safely derived, the topic is not a universal engineering baseline, and the topic is not merely a technology implementation choice.

## Wording
Use capability nouns/phrases such as `手機 App`, `多家公司使用`, `跨公司共享指定資料`. The UI renders exactly two choices: `要` and `不要`. Avoid `是否 ...` paired with `要/不要`.

## Inactive children
Dependent questions remain visible for discoverability but are disabled and do not require answers. A true answer submitted for an inactive question is invalid.

## Custom requirements
Every category offers `新增其他需求`. Adding the requirement itself means it is wanted; do not ask a second YES/NO question.
