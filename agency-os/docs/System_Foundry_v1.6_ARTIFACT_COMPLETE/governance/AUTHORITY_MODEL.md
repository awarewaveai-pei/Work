# Authority Model

Authority is explicit, least-privilege, time/scoped, auditable, and revocable. Agents do not gain authority from role labels or tool availability.

Required records for side-effecting work:
1. actor/agent identity
2. intent
3. risk tier
4. requested action and target
5. tool permission result
6. required authority level
7. grant/approval evidence
8. execution result
9. verification result
10. audit event id
