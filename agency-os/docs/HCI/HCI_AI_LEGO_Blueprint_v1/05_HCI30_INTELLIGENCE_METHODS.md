# 05 — HCI-30 Intelligence Methods

## Purpose

Define which analytical methods belong to HCI and how they are classified.

HCI methods are **domain methods**. They are not the same as AI LEGO's general cognitive methods.

---

# Stable methodological foundations

HCI may draw from:

- evidence-based reasoning
- Bayesian updating
- reliability engineering
- decision theory
- game theory
- incentive analysis
- organizational behavior
- trust research
- negotiation theory
- risk engineering
- network analysis
- behavioral science
- structured intelligence analysis when invoked through integration
- security/Zero Trust principles
- classical strategy as advisory heuristics
- self-reflection frameworks where explicitly separated from formal decision logic

## Method evidence grading

Recommended:

```text
Grade S — high-confidence standard / mature empirical or formal basis
Grade A — strong empirical framework
Grade B — established professional framework
Grade C — strategic heuristic / classical framework
Grade D — self-reflection framework
Grade X — experimental / under validation
```

Authority names never increase evidence weight by themselves.

---

# Method categories

## Psychology

Examples:
- Big Five / Five-Factor Model
- validated teamwork/communication instruments

Allowed:
- work preference
- communication tendency
- behavioral tendency

Forbidden:
- honesty determination
- criminality prediction
- automatic high-impact rejection

## Organizational trust

Use ability, benevolence/integrity concepts as inputs, but HCI extends them with:

```text
Reliability
Predictability
Alignment
Governance
Permission separation
```

## Cognitive bias defense

HCI must check analyst/user bias:

- confirmation bias
- halo effect
- horn effect
- recency bias
- availability bias
- anchoring
- loss aversion

A report may expose:

```text
Possible analyst bias:
Confirmation bias: MEDIUM
Halo effect: HIGH
Evidence diversity: LOW
Contradictory evidence reviewed: YES
```

## Negotiation

Applicable methods:
- interests vs positions
- BATNA
- reservation point
- alternatives
- leverage
- objective criteria
- information asymmetry

## Game theory

Applicable:
- signaling
- screening
- repeated games
- moral hazard
- adverse selection
- principal-agent problem

## Power analysis

Analyze:
- resource control
- information control
- decision authority
- gatekeeping
- dependency creation
- credit allocation
- blame allocation

## Conflict analysis

Analyze:
- trigger
- response
- escalation
- boundary behavior
- repair attempt
- resolution
- post-conflict behavior

## Classical strategy

Sun Tzu may be included as a **strategic/classical lens**, not scientific personality scoring.

Suitable dimensions:
- 知己
- 知彼
- 形勢
- 虛實
- 勢
- information asymmetry
- strategic terrain

Possible “cooperation terrain”:

```text
Money Terrain
Information Terrain
Legal Terrain
Relationship Terrain
Time Terrain
Technology Terrain
Reputation Terrain
```

Sun Tzu methods may not:
- diagnose psychology
- determine honesty
- directly increase/decrease formal trust scores

## Self-reflection

Examples:
- MBTI-style preference frameworks
- Enneagram
- 紫微
- 八字

Allowed:
- personal reflection
- analyst bias awareness
- communication reflection

Forbidden:
- enterprise trust scoring
- automatic risk decisions
- protected-class inference

## Method contract

Each formal HCI method should declare:

```text
method_id
version
category
origin
evidence_grade
allowed_scope
required_inputs
outputs
forbidden_uses
decision_weight
license_status
validation_status
```

## Important separation

```text
Domain Method
!= Cognitive Method
```

Examples:

```text
Big Five           → HCI Domain Method
Trust Model        → HCI Domain Method
BATNA              → Shared Strategy / HCI usable
Sun Tzu Lens       → Shared Strategic Lens / HCI usable
Red Team           → AI LEGO Cognitive Method
ACH                → AI LEGO Cognitive Method
Decision Matrix    → AI LEGO Cognitive Method
5 Whys             → AI LEGO Cognitive Method
```
