## Why so short

This is the disposition the mission brief's anti-overengineering instinct would predict should be small for a *pre-code, architecture-only* document: there is very little "dead weight" to cut from a system that hasn't been built yet. REMOVE became large in exactly one place -- the intelligence-methods catalog -- because that is the one part of V1 that names specific, independently-falsifiable claims (a named psychometric instrument, a named divination system) rather than architectural patterns. See `10_METHOD_SCIENCE_REVIEW.md` for the full evidence-grade reasoning behind both removals, and `22_OPEN_HUMAN_DECISIONS.md` HD-23 for the related (not-remove, but-decide) items in the same method cluster (Enneagram's evidence grade, Big Five instrument selection, confidence-percentage calibration).
