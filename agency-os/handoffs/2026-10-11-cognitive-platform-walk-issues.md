# 認知主權平台：正式站實走問題清單

- 日期：2026-10-11
- 怎麼走的：操作者自己登入 cognitive.aware-wave.com，Claude 在內建瀏覽器從首頁「陪我思考」開一個測試案子，一塊一塊做。
- 測試案子：「合夥人第三次改合約條件，這段合作要不要繼續？（測試用，稍後刪除）」

## A. 會讓整個平台壞掉的

| # | 問題 | 證據 |
|---|---|---|
| A1 | 每頁發出幾十個請求（產出與表達一頁約 60 個），再加上 14 格和選單預先載入，10 秒內超過 50 個請求，被 Cloudflare 全站限速規則封鎖 10 秒（429）。同一個 Wi-Fi 的一整班會一起被鎖。 | 瀏覽器記錄 494 個請求，`?_rsc=` 預載多筆 429；主機 API 記錄 0 筆 429。規則見 `runbooks/CLOUDFLARE-WAF-SETUP.md:146` |
| A2 | 主機 API 只有一個處理程序；每頁 60 次資料庫查詢。多人同時用會排隊、逾時。從沒做過多人測試。 | `docker logs cognitive-os-api`：Started server process [1] |
| A3 | AI 出錯時用 502，Cloudflare 把它換成自己的錯誤頁，使用者只看到「系統發生錯誤（502）」，真正原因不見。 | `ai_lego/apps/api/blocks/ai.py:53`；瀏覽器收到的是 Cloudflare 502 頁 |
| A4 | AI 回答上限太小，中文回答被截斷就失敗。共思考的 AI 鏡子寫滿 1500 token 被切斷。 | `ai_lego/platform/ai_actions/think.py:375`；`ai_usage` 表 THINK.mirror output_tokens=1500 |
| A5 | AI 回答被系統擋掉時，原因沒有記在任何地方，出錯查不出為什麼。 | 查證「請 AI 提拆法」502，output 315 token，API 記錄只有一行 502 |
| A6 | 蒐集器把最重要的來源丟掉：民法第 670 條、有限合夥法（全國法規資料庫）、法務部函釋被標「不算數」；徵信社網頁卻被算進獨立出處。 | 計算與模擬頁的來源清單 |
| A7 | 被限速時顯示「今天用得太多了，明天再試」，但當天 AI 只用了 6,699／200,000 token。訊息講錯。 | 產出與表達頁；`ai_usage` 表 |
| A8 | 「計算」被伺服器擋下時（缺樂觀／悲觀值），伺服器有回中文原因，頁面沒顯示，按了像沒反應。 | `POST docs/compute.request` 400 `COMPUTE_INPUT_REFUSED` |

## D. 做得好的（不要改壞）

- 首頁寫的話帶進開案；選目的推薦 6 塊路線，可重排。
- 每塊先問 AI 權限；沒准的角色真的被擋。
- 外化的 AI 鏡子照合約：只整理、指空白、問一題。
- 蒐集器真的有用（17 個獨立出處、來源卡、存檔核對碼）。
- 查核資料庫查得到 Cofacts。
- 計算給範圍、指出關鍵數字、標最弱的一環。
- 判斷的下一步自動帶到行動任務卡。
- 回顧把當初和後來並排，列出「你自己做到的」。
- 安全與治理：護欄、匯出 MD／JSON、模型與規則版本、不留紀錄。
