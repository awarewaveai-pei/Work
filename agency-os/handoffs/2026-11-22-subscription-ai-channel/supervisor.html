不會弄壞現有的東西

現有的 API 路徑原樣保留；訂閱是多出來的選項，拿掉就回到今天的樣子。

  • 現有的 API 路徑一行不刪。沒選訂閱模型時，文章、劇本、排程的行為與今天逐字相同。
  • 現有的 Codex 生圖網址、檔名、畫圖流程都不改；舊版執行程式照樣能畫。
  • 訂閱只給你本人員工或客戶按的功能一律走 API。主機上沒有登入的那一家訂閱，排程會自動跳過那一段。
  • AI 讀不到本機檔案寫字時關掉 AI 的所有工具；交回的文字若含本機登入憑證，整篇丟掉。
  • 額度用完不會停擺：照你選的走法換下一段，最後由 API 接手；成本頁寫明幾篇走了 API、花多少，並發通知。
  • 退路前三批沒有資料庫異動、沒有主機改動，退回一個版本即可。第四批停掉服務即可。
  • 工人工人只在自己的工作區改檔，不推送、不部署、不連主機；這些都由監工做。

風險與處置

每批一張表。工人交回的每條風險都要有處置：現在處理、實測驗證，或記下不處理的理由。

動工前（查證與實測）

  • K9Claude 的條款沒有明確允許無人排程；也不允許產品代別人使用訂閱。處置：你已決定排程可選 Claude。處置：訂閱只服務你本人；主機要不要登入 Claude 列為待決，不登入就等於關閉；每個網站可改選不含 Claude 的走法。
  • K2文章的提示詞裡有從網路抓來的內容，可能夾帶指令，騙 AI 把本機檔案內容寫進文章。處置：已寫進 K2：寫字時不給任何工具，交回前掃描憑證；M1 實際試騙一次。
  • K9筆電和主機共用同一份登入檔會互相讓對方失效。處置：已寫進設計：主機由你另外登入一次，不複製筆電的登入檔。
  • K7排程一輪只有 200 秒；Codex 寫一篇長文的耗時還沒量過。處置：實測驗證：M1 量三篇；超過兩分半才另開卡改成分兩輪，現在不先做。
  • M1ChatGPT 訂閱到 11-24 才有額度，Codex 寫字這條路在那之前無法實跑。處置：記錄：前三批以 Claude 訂閱實測；Codex 寫字與畫圖回歸留到 M1。
  • K4Codex 沒有額度，這段期間沒有另一家模型的審查。處置：每批由審查代理人看整批差異一次，並在工作日誌註明。
  • K1檔名和網址仍叫 codex-image，但之後也載文字與 Claude。處置：不處理：改名牽動約三十個檔、沒有行為收益，還會製造部署空窗；只更正檔頭說明。

第一批（三張卡交回後，整批審查找到的問題）

  • K3訂閱模型放進一般模型清單後，原本只走 API 的功能可能拿訂閱模型的名字去打 API 而失敗；每晚的模型檢查也會把它們報成壞掉。處置：現在處理：訂閱模型改成獨立清單，一般清單與價目表還原。退回工人重做。
  • K1筆電上若還是舊版執行程式，領到寫字工作會當掉，連帶畫圖也卡住。處置：現在處理：舊版程式一律只會被派畫圖。退回工人修。
