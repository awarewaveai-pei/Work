# Card 32 — GOVERN: "keep no record", crisis resources for every place, and the audit line of a case

## Decision
Required reading: `STEP34_SHARED_RULES.md` §10; `GOVERN.card.txt` lines 「不留紀錄」 (the option on the card), 「求助資源照你所在地給」, 「你可以查這個案子用了哪個模型、哪一版規則」, 「在地化」. Three small parts.

## Constraints
- **No record**: `assembler.intake` gains a field `no_record: bool` (`human_only`, default false; read `kinds/assembler.py` — S owns it: make the minimal addition and state it in the commit message). When true: closing the case (the existing close/finish action: find it with `grep -rn "def close\|status.*closed" ai_lego/apps/api/main.py ai_lego/data/repositories`) erases the whole case through the existing `erase_case` (rows and blobs), writes no `learn.history` line and nothing at person level about it, and the page said so in plain words BEFORE the person chose it (「關掉之後整個案子會刪掉，不能匯出」). The person can switch it off before closing; after closing nothing remains to switch. Test with the real erase and a real PostgreSQL: after closing, a count of every table for that case is zero and `learn.history`/`teach.*` rows naming it do not exist.
- **Resources per place**: a versioned content set `ai_lego/platform/resources/` (YAML + loader + `HISTORY.json` like card 40's lessons): `{place, kind in ('hotline','text','emergency'), name, how_to_reach, languages, hours, source: {name, checked_on}}`; places: 台灣 and the international set (take the existing step-1 data: find it with `grep -rn "1925\|安心專線\|lifeline" ai_lego`; reuse those entries exactly, do not invent numbers). A place with no entry gets the international set and the words 「這裡的資源我們還沒有，先給國際通用的」. The loader refuses an entry without a recorded `source`. Selection uses ONLY the person's place (`you_are_in` of the case, else `govern.location`; `places` rules of `AiAction` stay) and for groups each participant's own place for THEIR notice only (card 20's `collab.place`, readable by GOVERN only). Never a country list in code. Adding a place is a content change with a version bump (test).
- **Audit line**: a read route `GET /projects/{id}/govern/used` returns, for the case: the model name and version used by each AI turn (read how step 1 records it), the instruction-set version, and every ruleset name+version+fingerprint stamped on its cards/claims/runs (`Ruleset.stamp()` data is already stored; read `evidence.py` and the kinds); no content of the person's records. Plain Chinese labels.

## Files
`ai_lego/core/domain/kinds/assembler.py` (the one field), `ai_lego/platform/block_hooks/govern.py` (resources by place; close hook), `ai_lego/platform/resources/__init__.py` + `HISTORY.json` + `taiwan.yaml` + `international.yaml`, `ai_lego/apps/api/blocks/govern_group.py` (the audit route), `tests/unit/test_govern_no_record.py`, `tests/unit/test_resources.py`, `docs/platform/STEP34_CHECKLIST.md`, `agency-os/reports/review-debt.md`.

## Acceptance
Tests as described: no-record erase leaves zero rows; the warning text is returned by the intake/spec route before the choice; resources: Taiwan person gets Taiwan entries, an unknown place gets the international set with the fallback sentence, an entry without a source is refused, a text change without a version bump fails; audit route returns versions and no content (scan the JSON for a seeded private word); a person's place for a group notice is never visible to other members (visibility test). Mutations: skip the erase on close -> red; drop the source requirement -> red; leak the place to another member -> red; include record content in the audit route -> red.
