# Card 41 — TEACH: kinds, routes, AI practice partner, completion record

## Decision
Required reading: `STEP34_SHARED_RULES.md` §11; `docs/platform/step34-cards/TEACH.card.txt`; `BLOCK_BUILD_GUIDE.md`; card 40's loader. A person practises a method before using it: a 5-minute lesson, a practice case, five roles in turn, an after-action review. The AI is the practice opponent and gives feedback on the person's thinking moves. It never scores, never ranks, never asks for something vulnerable.

## Constraints
- Kinds in `kinds/teach.py`: `teach.run`, `teach.aar` (person-owned, user author), `teach.completion` (person-owned, author `system`, written ONLY by a hook when every lesson the course for that package requires has a `teach.run` by this person: a person cannot write it; `authors={"system"}`), shapes in §11. A `teach.run` names a `lesson_version` that exists in the loader; save refuses an unknown one. `teach.run` records which of the five roles was practised.
- Practice and real cases stay apart: a `teach.run`/`teach.aar` is person-owned and never attached to a real case; a person may use a real case for practice only by consenting (the card: 「絕不讀：你真實的案子，除非你同意拿來練」): implement the consent as a person-owned `teach.practice_consent` kind `{project_id}`; without it the actions below refuse any context naming a real case.
- AI actions in `ai_actions/teach.py` (read `ai_gate.AiAction`, `collab_contract` permissions): `opponent` (plays the role opposite to the person's, reads the lesson, the practice case and the person's `teach.run` notes) and `feedback_on_moves` (reads the person's run notes, returns feedback keyed to named thinking moves, e.g. 「你還沒寫反例，就下了結論」). Both: output kind author `ai`; no score/rank key; may not ask the learner to disclose something private (the instruction says so and a test scans output shapes for fields named like feedback scores); the person can skip, redo, switch case at any time (routes accept re-runs; nothing is locked).
- Routes in `apps/api/blocks/teach.py`: list lessons for a subject (the loader's `reviewed_only()` is NOT applied: drafts show with 草稿), get a lesson, list practice cases, start/save a run, save an after-action review, get my completions. Everything person-owned goes through the existing `/me/docs/{kind}` generic routes where they fit; add routes only for what the generic ones cannot do (the lesson/case reads). No other person's `teach.*` record is readable by anyone (add each kind to card 11's reviewed list).
- The completion hook shows up as a plain notice to the person ("你上完了『…』的課"), nothing else.
- Local examples: each practice case has `place`; the list route prefers cases for the person's place (`govern.location`), falls back to others and says so.
