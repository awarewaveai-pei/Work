# Card 21 — COLLAB: the "how the group sees it" rule and the AI's three jobs

## Decision
Required reading: `STEP34_SHARED_RULES.md` §8 and §7 (`collab.restatement`); `COLLAB.card.txt` lines on 「大家怎麼看」 (bridging, X's published approach) and 「AI 能做什麼 / 不准做什麼」; `STEP2_SHARED_RULES.md` §5 (AI gate); `ai_actions/` examples. Two parts.

## Constraints
- **Agreement view (pure, deterministic, tested):** `agreement(stances, history, members)` in `apps/api/blocks/collab.py` (or a module `platform/collab_agreement.py`), version and rule text in `platform/rulesets/collab.py` (a ruleset `collab.agreement`, HISTORY). Inputs: each member's stance per option now, and the group's stance history from earlier rounds. Method (spec in §8, implement exactly): build per-member agreement vectors over all options with a recorded stance; split members into 2 clusters by deterministic 2-means (init = the two most distant members by Hamming distance, ties by member id; fixed iteration cap 20); an option is `agreed_across` only when it has ≥1 agree in each cluster and no objection in either (an objection never lets an option show as agreed); also return the same table recomputed after excluding the top 10% of members by number of stances cast (ceil, at least 1 only when there are ≥10 members); members `pending_review` are excluded and listed; fewer than 3 effective members or no multi-option history -> `{insufficient: true, why: "還不夠看出誰跟誰不同"}` and NO agreed list. The function never returns counts as a winner signal: it returns for each option `{agreed_across, objections: [..reasons..]}` and nothing numeric that ranks.
- **AI actions** (`ai_actions/collab.py`; the permissions are the card's: AI organises differences, restates each side, points out who has not been heard): `organise_differences` (reads the group's visible positions/stances through `visibility.visible` for the CALLER; returns clusters of differences in words, no ranking), `restate_positions` (writes one `collab.restatement` per member about THAT member; it is visible to the others only after that member confirmed it; the member can say 「說錯了」 which stops the turn, records `govern.stop`-style handback and writes nothing more about them), `not_yet_heard` (names members with no record for the round, nothing else about them). Shared AI rules: may not speak for any side, may not declare consensus, may not hide a minority view, may not rank participants (no rank/score key); each text from another member reaches the model fenced as someone else's words (`AiAction.quoted`); the crisis check runs on the caller's words; an action only runs for a current member.
- Handback: if anyone objects or asks to reopen during the AI's turn (a `collab.reopen` or an objection newer than the context) the AI stops BEFORE the model call and the response says whose turn it is.

## Files
`ai_lego/apps/api/blocks/collab.py` or `ai_lego/platform/collab_agreement.py`, `ai_lego/platform/ai_actions/collab.py`, `ai_lego/platform/rulesets/collab.py`, `tests/unit/test_collab_agreement.py`, `tests/unit/test_collab_ai.py`, `docs/platform/STEP34_CHECKLIST.md`, `agency-os/reports/review-debt.md`.

## Acceptance
`test_collab_agreement.py` (pure function, no database): the card's example shapes (3 members, two camps: an option both camps accept is `agreed_across`, an option only one camp accepts is not; one objection blocks it); exclusion of heavy raters changes the second table as specified; held members excluded and listed; insufficient cases; determinism (same input twice -> identical output; permuting member order -> identical output); no numeric ranking key in the output (scan). `test_collab_ai.py`: restatement invisible to others until confirmed; 「說錯了」 stops the turn and the AI writes nothing more about that member; no action runs for a non-member or a left member; the AI never writes a `collab.stance` for anyone; a pasted/other member's text is fenced; handback before the model call (the fake provider sees zero calls). Mutations: let an objection still show agreed -> red; skip the 2-means tie rule -> red (order permutation test); reveal a restatement early -> red; allow the AI to write a stance -> red.
