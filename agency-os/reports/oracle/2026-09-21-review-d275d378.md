  Recommendation: Require a durable dispatcher outbox/retry contract or add idempotent notification-pending state before slice 1.

  C3 reuses the same lease token for Trigger.dev retries and accepts that token even after expiry. A timed-out attempt that is still finishing can overlap a retry or reclaimed execution, causing duplicate renderer work and races in streak, incident, and recovery side effects. Result upsert alone does not fence those effects.
  Recommendation: Rotate an attempt-generation token on retry/reclaim and require it for renewals, writes, and side effects.

  Recommendation: Define the slice-1 `hour_utc` default and specify catch-up semantics while preserving one daily run key.
