# Codex Adversarial Review (4 rounds)

Target: scripts/verify-head-typecheck.ps1 + scripts/lib/compare-installed-deps.mjs
Verdict: needs-attention

Four rounds against the stale-dependency gate. Rounds 1-3 are fixed in the reviewed tree; round 4
is accepted as a documented contract boundary rather than a defect. Dispositions below each finding.

Findings:
- [high] Hidden lockfile trusted without validating the physical dependency tree (scripts/lib/compare-installed-deps.mjs)
  npm's node_modules/.package-lock.json records what npm believes it installed, so a package
  directory deleted or mutated afterwards still reads as in sync while tsc resolves something else.
  This moved the trust boundary rather than removing it.
  DISPOSITION: FIXED. The comparator no longer reads the hidden lockfile at all -- it walks the real
  package directories and reads each package's own package.json. Verified: fixture "package
  directory physically deleted" exits 1; live tree comparison costs 139ms.

- [high] Workspace links always fail the version comparison (scripts/lib/compare-installed-deps.mjs)
  npm records a workspace symlink as { link: true, resolved: "packages/foo" } with no version on the
  node_modules entry. Comparing a placeholder against the linked package's real package.json would
  fail every clean npm ci.
  DISPOSITION: FIXED. A version is compared only when the lockfile states one; presence on disk is
  always required. Verified against the live lockfile first: 0 link entries and 0 versionless
  non-optional entries, so the bug was latent, not active. Fixtures "workspace link present" (exit 0)
  and "workspace link declared but absent" (exit 1) added.

- [medium] Unreadable package directories silently omitted from the installed set (scripts/lib/compare-installed-deps.mjs)
  Node and TypeScript resolve node_modules/foo/index.js with no package.json at all, so an
  undeclared module of that shape was invisible to the comparison.
  DISPOSITION: FIXED AS A CLASS, not an instance. All three findings above are one failure: side 2
  kept measuring a proxy for "what TypeScript can resolve" instead of that set itself. Membership is
  now decided by the DIRECTORY (any non-dot entry under a node_modules or @scope dir); package.json
  only supplies the version; an unreadable or corrupt manifest is itself reported as drift. Verified:
  3 new fixtures (bare index.js module, deleted manifest, corrupt manifest) all exit 1, and the live
  490-package tree still reports DEPS_IN_SYNC exit 0 -- the stricter rule adds no false drift.

- [medium] Same-version package mutations accepted as in sync (scripts/lib/compare-installed-deps.mjs)
  The comparator checks names and versions, not integrity or contents, so a package mutated in place
  while keeping its name and version passes.
  DISPOSITION: ACCEPTED AS A DOCUMENTED BOUNDARY, not fixed. True, but a different contract. Proving
  content equivalence means re-deriving integrity for all 490 packages, which is npm ci, which is
  exactly what -Install already runs; npm itself verifies integrity at download/extract time, not
  against an existing tree, so no cheaper primitive exists. The invariant this gate exists to enforce
  is the declared dependency SET and versions, and the production failure it was built for was a
  MISSING package (TS2307 pixelmatch), not a tampered one. Recorded in the file header as an explicit
  "what this does NOT prove" note pointing at -Install, so the next reader does not over-trust it.
