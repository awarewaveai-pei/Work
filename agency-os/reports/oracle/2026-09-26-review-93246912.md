# Codex Adversarial Review

Verdict: needs-attention

No-ship: the checker has false-green paths for form visibility and the “only primary link” invariant; browser coverage also misses key tab regressions.

Findings:
- [high] Form-state checker can pass while fields are hidden in both states (Projects/internal/cognitive-engineering-os/docs/mockups/check-mocks.py:640-643)
  `shown` records only the nearest `data-when` ancestor for each form and unions those labels. A form nested under `data-when="empty"` inside `data-when="result"` would be hidden in both states by `run-form-script.html`, yet the checker would still report visibility in both states. This directly defeats the requirement that every run-page state visibly exposes fields.
  Recommendation: Compute effective visibility across every ancestor for each state, or reject contradictory nested `data-when` containers; assert that at least one form with visible textareas exists in each browser state.
- [medium] Start-card rule does not enforce that there is only one primary link (Projects/internal/cognitive-engineering-os/docs/mockups/check-mocks.py:685-693)
  The checker inspects only buttons/links found inside the first `.btns` container (`bs`). An additional `<a class="btn primary">` elsewhere in `#start` would be ignored, so the stated “only primary link opens the run page #new” invariant can be false while the checker passes.
  Recommendation: Inspect all actionable `.btn` elements within `#start`, require exactly one primary action, and require that it is the first action with the `#new` destination.
- [medium] Browser test does not protect the full keyboard/hash contract (Projects/internal/cognitive-engineering-os/docs/mockups/chips-test.cjs:186-195)
  The tab behavior test covers ArrowRight, End, wrapping, and initial navigation to `#panel-read`, but never exercises Home, ArrowLeft, or a runtime `hashchange`. A regression in those required keyboard and hash paths could therefore pass both the browser test and the static checker.
  Recommendation: Add assertions for Home/ArrowLeft focus and selection, change `location.hash` after load and verify the corresponding panel, and verify that exactly one panel remains visible after each transition.
