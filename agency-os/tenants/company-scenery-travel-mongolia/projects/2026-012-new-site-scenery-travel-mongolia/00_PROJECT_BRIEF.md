# Project Brief - 2026-012 New Site Scenery Travel Mongolia

## Project Type
- New site build（從零建站）

## Business Context
- Client: Scenery Travel Mongolia
- Current presence: Instagram only
- Strategy: 建立英語官方網站，承接國際旅客詢問並轉換
- Target market: International travelers（Asia, Europe, North America）

## Delivery Objective (Phase 1)
1. 完成 tenant/site/project 骨架 + Discovery
2. 建立 staging 環境（WordPress + 必要外掛基線）
3. 完成最小可上線頁（首頁、行程頁、詢問頁、法遵頁）
4. 通過 Pre-Production Gate → production 首次上線

## Scope (This Sprint)
- In scope:
  - Staging 環境建立與驗收
  - 最小可上線頁面（EN）
  - 詢問表單路徑
  - 必要法遵頁面（隱私、取消/退款）
  - Analytics 基礎
- Out of scope:
  - OTA / 訂房系統
  - 多語系（Phase 2）
  - 付款閘道（Phase 2）
  - 客製旅程預訂系統

## Definition of Done (Phase 1)
- `core/ENVIRONMENT_REGISTRY.md` staging + production 欄位填入
- Pre-Production Gate 全部 PASS
- Production URL 可達，詢問表單可用
- Day 1 骨架 + Discovery 記錄於 WORKLOG.md
