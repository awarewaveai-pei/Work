# AwareWave 剪輯、合成與骨架整合規劃

日期：2026-11-02（Asia/Taipei）。狀態：規劃，尚未完成引擎接入。

## 已確認需求與現況

使用者要求完整影片剪輯、動畫／視覺特效／合成、多軌、精細裁切、轉場、調色、字幕、音訊混合、動態字幕、片頭、圖層、遮罩、關鍵影格、動畫曲線、表達式、3D 攝影機，以及 2D、3D 綁骨架。

目前 `scripts/tools-editor.js` 是自製 V1、V2、T、A1、A2 五軌編輯器，後端由 `backend/editor-export.cjs` 輸出；這不是 FilmCraft／EffectCraft。4178 正在服務，不為規劃工作重啟。現有專案須保留、可繼續使用。

【分鏡靈感】及其設計保護檔完全不在修改範圍。外觀持續取自 `backend/appearance.cjs` 指向的 AwareWave 主題與表單來源，不另建一套配色。

## 使用者入口

在現有「應用工具」下安排三個工作區：影片剪輯、動畫與合成、角色與骨架。共用素材庫、專案入口、任務紀錄與成果；不是三個互不相通的網站。專業工作區可展開，但側欄、返回、關閉與焦點行為必須保持正常。

使用流程：素材匯入 → 剪輯成片 → 將選定片段送去動畫／合成或角色動畫 → 產生帶來源連結的中間成果 → 回原時間軸 → 最終輸出。可返回原生專案再編輯，不能只留扁平化影片。

## 引擎決策與邊界

1. 剪輯以 FilmCraft 作候選，動畫／合成以 EffectCraft 作候選。兩者有功能重疊；先用同一份最小剪輯案例驗證 EffectCraft 是否已滿足剪輯必需項。若滿足，優先減少一套引擎；未滿足才導入 FilmCraft，並記錄具體缺口。這是待驗證的選型，不是已完成的功能承諾。
2. EffectCraft 的 Puppet 已有官方文件與程式碼依據，可用於網格／控制釘變形；不能直接視為完整 2D 骨骼階層、IK／FK 與蒙皮系統。
3. 完整骨架以 Blender 作本機處理引擎候選。3D 需骨骼建立／階層、權重、IK／FK、姿勢、動作匯入與重定向；2D 需分層圖片網格、骨骼與權重，另可支援 Grease Pencil。圖片角色與 Grease Pencil 是不同素材流程，不能混為一談。
4. Blender 本機程式不能直接當成 iframe 網頁。網頁內選骨骼、拖控制器、改權重等操作需要專門的瀏覽器視窗與命令橋接。只提供「開啟 Blender」或背景渲染，不能算完成網頁內綁骨架。這部分須獨立排期。
5. 原生引擎專案各自保留，不承諾以一種 JSON 無損取代所有格式。統一的是外層專案清單、素材 ID、版本與任務介面。跨引擎先採片段／透明序列交換；不承諾所有特效、骨架或表達式可跨引擎無損編輯。

## 技術接入

- 4178 保留為唯一使用者入口。新增專用工作區頁面與引擎 adapter，由現有 Node 後端協調；引擎靜態檔隔離放置、固定版本。先驗證官方 Web/WASM 成品，不先重寫整套 UI 或全量編譯。
- adapter 明確提供載入、能力查詢、素材匯入、保存／重開、命令、預覽、輸出、取消與釋放資源。上游 Web 介面未具備者，列缺口，不用假按鍵替代。
- WASM 在工作區內載入，耗時操作不阻塞側欄；測試記憶體釋放、GPU／瀏覽器相容性、字體、跨來源隔離與現有嵌入模式的衝突。無法滿足時採受控本機 worker，不讓服務衝突導致另開使用者埠。
- 專案外層包含格式版本、引擎及其版本、引擎專案檔引用、素材引用、時間基準／影格率、輸出設定與版本紀錄。影片時間採明確整數影格／有理時間，不靠浮點數累加。
- 所有引擎共用實際素材檔，不重複上傳；產生代理檔並保留原檔。MOV／MP4 是容器，另檢查實際編碼與旋轉資訊；不支援的預覽編碼轉代理，不宣稱副檔名相同就一定可解碼。
- 輸出走共用任務：進度、取消、錯誤、重試與成果；中間透明成果優先採經驗證的 RGBA 序列及獨立音訊，避免先假設所有瀏覽器都能播放帶透明的 MOV。
- 新專案格式獨立儲存。舊五軌專案以明確支援欄位轉換並顯示未支援項；先保存原版，再轉入，不覆蓋或靜默遺失設定。
- 表達式執行於受限環境，有時間／資源限制，不能直接取得主工作台權限或伺服器檔案。

## 實作順序與驗收

### 0：固定基線與最小引擎試作

固定引擎版本、檢查授權與依賴，保存現有專案／設計雜湊。使用同一份短片、圖片與音訊，測試 Web 引擎啟動、多軌裁切、字幕、混音、保存／重開及輸出。記錄缺口後才決定一套或兩套剪輯／合成引擎。只在隔離資料測試，不接付費生成。

驗收：從匯入到真實輸出完整跑通；重開不丟編輯；聲音存在；預覽與輸出在指定時間點一致；側欄／關閉正常。未通過不擴大實作。

### 1：影片剪輯

落地多軌、移動／分割／裁切、轉場、調色、字幕軌及匯入／匯出、音量／淡入淡出與混音、撤銷／重做。動態字幕與合成工作區銜接。支援既有五種比例：16:9、9:16、1:1、4:5、4:3。

驗收：MOV／MP4 + 圖片 + 兩段音訊 + 字幕做成完整短片；保存、關閉、重開；獨立解碼輸出，核對長度、比例、裁切、字幕、音軌及轉場。

### 2：動畫與合成

落地圖層、遮罩、關鍵影格、曲線、表達式、動態字幕、片頭、3D 攝影機與片段送回剪輯。EffectCraft Puppet 另標示為變形工具。

驗收：完成一段有動態字幕、遮罩、緩動與攝影機移動的片頭，回主時間軸輸出；保存後能再改原合成，不只重播影片。

### 3：2D 骨架

分層角色匯入、建骨骼／階層、綁定、權重調整、IK／FK、姿勢與關鍵影格，網頁操作與處理引擎橋接。

驗收：在工作區替分層角色建立手臂／腿骨，改權重、用 IK 擺姿勢、做短動作，保存重開再改，透明成果回時間軸。Puppet 控制釘展示不算通過此項。

### 4：3D 骨架

模型載入、骨架建立與檢視、蒙皮權重、IK／FK、動作匯入、骨架映射／重定向、動畫曲線及攝影機，處理任務回傳預覽與成果。

驗收：自有或合法測試角色完成綁定，匯入動作並映射到不同骨架；修姿勢後保存／重開，渲染回影片專案。初版先鎖定經驗證的模型／動作格式，逐項公布，不能把所有 FBX／GLB／BVH 相容性當既成事實。

### 5：主站整合

本機階段完成後，再把 API／儲存 adapter 接 app.aware-wave.com。現有後端僅接受本機 Host／Origin，不能直接改網域就宣稱上線。遠端階段需要主系統身分驗證、檔案儲存、任務 worker、權限與隔離。

WordPress aware-wave.com 同時支援工具嵌入及內容／成果使用。需登入的工具由 app 管理身分；嵌入採明確允許的來源與訊息協定，不把服務金鑰放入 WordPress 前端。遠端網頁不能假定可直接呼叫使用者的 localhost Blender，需選遠端處理或有認證的本機配套。

自用期間不扣平台點數；保留用量事件與未來訂閱權限接口，記錄實際處理／供應商成本不等於現在收費。

## 範圍與節省反覆工作的方式

先做第 0 階段的完整最小流程，不同時重寫三套編輯器。每階段以可操作專案與實際輸出驗收；失敗就處理具體阻塞，停止擴充。程式變更按小範圍測試與 Claude 跨模型審查；不反覆全站測試、不重複打 ZIP、不任意更換 4178。專業引擎預設 UI 可用於試作，但不當成已完成 AwareWave 外觀整合。

這是多階段產品開發，不能承諾一次修改就具備完整專業剪輯、合成及 2D／3D 骨架系統。每階段交付明確標示已完成、限制與下一項。
