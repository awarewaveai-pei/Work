## 4. 操作者決定（2026-11-06「照建議」）

- 決定 1：列表頁照參考做，專案卡多一行「屬於 專案 › 第 N 集」，兩邊開同一份剪輯檔（ED.9 與 PJ.1 一起對齊）。
- 決定 2：內建曲庫用我們的音樂工具生成自己的曲子（ED.6 開工前列曲目清單與費用給操作者確認）。
- ED.1 不放「剪輯 Agent」按鈕：沒有功能的按鈕不上線，ED.13 才加。
- 決定 3（2026-11-06）：版型與功能跟參考一模一樣；參考沒有的功能保留、搬到對應位置——片頭→文字分頁、調色→片段屬性、影格率→整片設定›輸出、峰值表→音訊分頁、多軌→時間軸最後一列「新增 X 軌」。左側欄只留參考的八格。新建視窗比例卡多一張 4:3（AwareWave 比例較多）。
- 預覽畫質 720P／1080P 尚未做：要先有低解析度預覽檔，沒有就只是假按鈕。

### 原始選項

1. **專案列表 vs PJ.1**：`docs/engine-route-plan-20261106.md` 答 4 定了「剪輯專案收進專案頁的集，剪輯器不再有自己的清單」。參考有自己的列表頁。建議：列表頁照參考做，每張卡多一行「屬於 專案 › 第 N 集」；兩邊打開的是同一份剪輯檔。
2. **內建配樂／音效／環境音的曲子從哪來**：對方 170 首不能用。選項：用我們的音樂工具生成一批自己的曲子（要花生成費）／先上架空的分類，之後再補。
