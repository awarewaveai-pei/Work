# 社群管理平台 — 功能總表（對照 Metricool／Buffer／Postiz）

> 建立 2026-10-14。操作者要求「功能完善的平台」：這張表是完整範圍，不是第一版範圍。
> 欄位：M = Metricool（[planner](https://metricool.com/planner/)、[pricing](https://metricool.com/pricing/)、help center）；B = Buffer（[publish](https://buffer.com/publish)）；P = 我們自架的 Postiz 後台已有（[public API](https://docs.postiz.com/public-api/introduction.md)）；樣稿 = `mockups/social-manager-mock.html` 現況；版 = 排在第幾版。
> 版次定義：**V1** = 自己管多個品牌就能用；**V2** = 開放外部客戶訂閱前要有；**V3** = 之後。平台審核通過與否不影響版次，只影響哪個平台先亮。

4. 發佈紀錄與失敗通知。
5. 媒體庫。
6. 發佈後附平台連結。
