1. 這條路解什麼問題40 秒

怎麼讀先看「能回答／不能回答」，再看站列。你要做的不用做；你的問題如果不是「幾個選項選一個」，這條路不適合，去第 5 步按第三顆按鈕。

「做一個決定」把一個要在幾個選項裡選一個的問題，走三站：先把問題講清楚，再看自己的強弱與外面的機會威脅，最後用你自己定的準則和權重把選項打分 [1]。

這條路能回答要決定的到底是什麼、成功長什麼樣；我們的強弱、外面的機會威脅；幾個選項按你的準則哪個最好、哪個權重一改結果就翻。
這條路不能回答市場會不會買單（除非接上資料蒐集）；權重不會替你定，那是你的價值判斷；「該不該」的道德問題。
第 1 站 問題陳述→第 2 站 SWOT→第 3 站 加權決策矩陣→總結頁

什麼時候用：選項已經有兩個以上、大家意見不一、想要一個能說清楚理由的決定。什麼時候不用：只有一個選項（那是「做不做」，用可行性那條路）；還不知道問題是什麼（先單獨跑問題陳述）。

2. 三站各做什麼、帶入什麼、要你填什麼1 分鐘

怎麼讀先按你的領域看例子；每站三行：回答什麼、從上一站帶入什麼（你不用重填）、還要你填什麼（紅字）。你要做的按一個領域；把你的決定在心裡套三站試一次。
例子領域：
第 1 站 問題陳述
回答什麼：要決定的到底是什麼、誰受影響、成功長什麼樣。
帶入什麼：你建立專案時寫的那段話。
還要你填：誰受影響、成功的 2–3 個條件。
例：WuSheng 課程要不要改成線上＋實體混合；成功 = 主動分享不降、遠地能參加。
例：要不要和某機構合辦課程；成功 = 對方準時付款、我們保有教材權。
例：要不要開新品類；成功 = 三個月退貨率不高於現有品類。
例：要不要搬到市區；成功 = 通勤少一半、房租不超過三成。
第 2 站 SWOT
回答什麼：做這個決定，我們的強項、弱項、外面的機會與威脅。
帶入什麼：第 1 站的問題陳述與成功條件，自動變成「脈絡」。
還要你填：S／W／O／T 各至少 2 條（可讓 AI 起草，你改）。
例：強項 = 帶領者熟線上工具；威脅 = 線上人多時分享會掉。
例：強項 = 我們的課程完整；威脅 = 對方過去延後付款。
例：強項 = 供應商穩；威脅 = 尺寸類退貨高。
例：強項 = 工作在市區；威脅 = 房租上漲。
第 3 站 加權決策矩陣
回答什麼：幾個選項按你的準則和權重，哪個分數最高、哪個權重一改就翻。
帶入什麼：第 2 站的 S／W／O／T 自動變成準則候選。
還要你填：每個準則的權重——這是你的價值判斷，系統不代填。
例：準則 = 分享不降（權重 5）、遠地可參加（3）、帶領者負擔（4）。
例：準則 = 付款可靠（5）、教材權（5）、曝光（2）。
例：準則 = 退貨率（5）、毛利（4）、上架工時（2）。
例：準則 = 通勤（4）、房租（5）、環境（3）。

記法：第 1 站定「要決定什麼」，第 2 站看「自己和外面」，第 3 站「用你的權重打分」。例子跟著你進來的那條線走；不會拿你真實填過的案例當教材。

站一句話你的判斷

4. 怎麼走：兩種走法、每站你要做的、常見錯誤40 秒

怎麼讀先選走法，再看每站的好例壞例。你要做的決定你要一站一站走，還是一次跑完。
一站一站走：每站停下來給你確認，可以改順序、中途換方法。第一次走建議這個。
一次跑完：三站自動跑，跑完再逐站看。適合已經走過、只是換資料。
好：第 1 站把成功條件寫成看得到的數字（分享人數不降、遠地 ≥ 3 人）。
壞：第 1 站寫「希望變好」。（好在哪？誰看得到？）
好：第 3 站的權重自己填，填完看敏感度。
壞：權重讓 AI 填。（那就不是你的決定）
✕跳過第 1 站：直接做 SWOT，最後發現大家在決定不同的事。
✕退回不重跑：改了第 1 站卻沿用第 3 站的分數；系統會把後面的站標失效，照著重跑就好。
✕把分數當答案：第 3 站的分數是「按你的權重」算的；先看哪個權重一改就翻，再決定。
自我檢查（20 秒，點開看答案）
「權重」在哪一站填、誰填？第 3 站，你填；AI 只能起草準則候選。
改了第 1 站的成功條件，第 3 站要不要重跑？要；系統會把第 2、3 站標失效並提醒。
