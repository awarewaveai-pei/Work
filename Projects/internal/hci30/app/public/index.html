HCI-30 信任評估報告

信任評估案件列表

HCI-30 幫你用真實證據，快速判斷「這個人或這家公司值不值得信任」——不用光憑直覺，你蒐集事實，系統自動算出信任分數，最後由你做決策。

1開一個案件說明調查對象與原因
→
2新增證據寫下查到的事實、聽到的說法
→
3取得信任報告系統自動評分，你做最終決策
＋ 開立新案件

選一個最符合這次調查性質的分類，會影響適用的規範。

數字愈大代表這次調查愈敏感、應愈嚴謹看待；實際分級標準另由內部規範決定，不確定可先選最低再視情況調整。

合成開發資料。真實 API ＋真實 RLS 保護的 Postgres，非模擬系統。

目前尚未建立登入機制，租戶身分暫以下方按鈕手動切換（正式版會是真實登入）。
